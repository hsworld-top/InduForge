# 设计器工程全局脚本面板设计

## 目标

将设计器左侧脚本面板优化为“工程全局脚本配置中心”，明确区分：

- 左侧脚本面板：工程全局脚本，对整个工程预览和运行态生效。
- 右侧高级面板：当前页面脚本，仅对当前页面生效。

脚本编辑弹窗抽成通用组件，工程全局脚本和页面级脚本共享编辑体验，但保存位置和作用域文案不同。

## 作用域边界

工程全局脚本保存到 `globalScripts`。

页面级脚本保存到当前页面生命周期配置。

通用编辑弹窗只负责编辑脚本内容和辅助插入，不直接决定保存位置。

## 信息架构

左侧脚本面板标题改为“工程全局脚本”。

面板包含四个固定区域：

1. 系统脚本
   - 固定两项：系统启动、系统关闭。
   - 不允许新增、删除、复制、移动。
   - 允许启用、停用、编辑脚本内容。

2. 全局定时器
   - 可新增多条。
   - 每条显示名称、启用状态、执行间隔、描述。
   - 支持新增、编辑、复制、删除、分组、移动。

3. 全局变量监听
   - 可新增多条。
   - 每条显示名称、监听变量、启用状态、描述。
   - 支持新增、编辑、复制、删除、分组、移动。

4. 全局自定义函数
   - 可新增多条。
   - 每条显示函数名、参数、启用状态、描述。
   - 支持新增、编辑、复制、删除、分组、移动。
   - 可被组件事件、绑定脚本、页面脚本调用。

## 面板交互

系统脚本区域不显示新增按钮。

其他区域标题右侧显示新增按钮。

脚本条目点击选中，双击打开编辑弹窗。

条目右侧提供更多操作入口，承载编辑、复制、移动、删除。

折叠区域保留，但标题和条目内容需要体现“工程全局”语义，避免像普通文件目录。

## 通用脚本编辑弹窗

新增通用组件 `ScriptEditorDialog.vue`。

组件职责：

- 显示脚本作用域标签：工程全局 / 当前页面。
- 显示脚本类型：启动、关闭、定时器、变量监听、自定义函数、页面生命周期。
- 编辑脚本代码。
- 显示和编辑脚本元信息需要外部传入或通过插槽提供。
- 提供变量枚举、自定义函数插入、页面变量插入、页面组件插入。
- 支持 Ctrl+S 保存。
- 有未保存内容时关闭弹窗需要确认。

建议输入：

```ts
type ScriptScope = 'global' | 'page'

type ScriptKind =
  | 'systemStartup'
  | 'systemShutdown'
  | 'timer'
  | 'variableChange'
  | 'custom'
  | 'pageMounted'
  | 'pageUnmounted'
```

弹窗不直接写 store。父组件处理保存。

## 高级面板调整

高级面板中的脚本入口文案改为“当前页面脚本”。

页面脚本弹窗复用 `ScriptEditorDialog.vue`。

页面脚本弹窗顶部必须显示“当前页面”作用域。

页面级脚本不出现在左侧工程全局脚本面板中。

## 非目标

不改变运行时脚本执行语义。

不新增新的脚本类型。

不修改脚本数据持久化接口。

不引入在线调试控制台。

## 验收标准

- 左侧脚本面板标题和区域文案能明确表达工程全局作用域。
- 系统启动、系统关闭只显示固定两项，不出现新增入口。
- 定时器、变量监听、自定义函数仍可新增多条。
- 工程全局脚本和当前页面脚本使用同一个通用编辑弹窗。
- 弹窗顶部能区分“工程全局”和“当前页面”。
- 现有脚本保存、预览运行逻辑不回退。
