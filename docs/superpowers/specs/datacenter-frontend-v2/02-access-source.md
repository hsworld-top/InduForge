# 子文档 02：接入源工作区

> 更新时间：2026-05-15
> 上级文档：[数据中心前端 v2 设计](../2026-05-15-datacenter-frontend-v2-design.md)

## 1. 页面定位

- **接入源是数据点的来源**。这个工作区让用户**快速配置、快速测连通、快速看到产生了多少数据点**。
- 单工程预期 500–1000 个接入源，**卡片网格 + 分类筛选**是合理形态。
- 涉及"写 SQL、管 MQTT Tag、看消息、跑短时预览"这种需要大空间的能力，走**二级工作台**（接入源专属全屏，仍在数据中心内）。

## 2. 主区布局

```
┌─ 工具栏 ───────────────────────────────────────────────┐
│  [搜索] [类型pill群] [状态pill]    [刷新] [新增连接]      │
├─ 主区：卡片网格 ───────────────────────────────────────┤
│  ┌────────────┐ ┌────────────┐ ┌────────────┐         │
│  │ 🟢 已连接   │ │ 🔴 断开    │ │ ⚪ 未连接   │         │
│  │ MySQL      │ │ MQTT       │ │ TDengine   │         │
│  │ 生产库      │ │ EMQX       │ │ 时序主库    │         │
│  │ host:3306  │ │ tcp://...  │ │ host:6041  │         │
│  │ 24 数据点   │ │ 156 数据点  │ │ 0 数据点    │         │
│  │      [打开] │ │      [打开] │ │      [打开] │         │
│  └────────────┘ └────────────┘ └────────────┘         │
│  ...                                                    │
│  ┌─────[+ 新增连接]─────┐                              │
└────────────────────────────────────────────────────────┘

详情抽屉（点卡片任意空白处弹出，单页滚动，480px）
二级工作台（点卡片"打开"按钮，全屏覆盖主区）
```

### 交互区分

- **单击卡片**：右侧抽屉打开详情（看配置 / 测连通 / 跳转关联数据点）。
- **点卡片"打开"按钮**：进入二级工作台（写 SQL / 管 Tag / 看消息 / 跑预览）。
- **点卡片"⚙编辑"图标**：直接打开编辑 dialog。

## 3. 工具栏

- 搜索框：搜索名称 / 地址。
- 类型筛选 pill 群：`全部 / 数据库 / 消息流 / 工业协议`。展示当前项目存在的分类，零数量分类不展示。
- 状态筛选 pill：`全部 / 已连接 / 断开 / 未连接 / 异常`。
- 工具栏右侧：刷新、新增连接（primary 按钮）。

**移除**：排序 pill（卡片网格按名称字典序固定，简化）。更多筛选 popover。"模板优先 / 协议高级"两种入口（合并为单一新增 dialog）。

## 4. 卡片信息

```
┌────────────────────────────┐
│ [图标]              [状态]  │  ← 左上协议图标 + 右上状态徽标
│                            │
│ 接入源名称（粗体）           │
│ 协议类型 · 脱敏地址          │
│                            │
│ N 数据点                    │
│              [打开 →] [⚙]   │  ← 主操作 + 编辑
└────────────────────────────┘
```

| 字段       | 来源                             | 备注                                                                                                              |
| ---------- | -------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 图标       | 协议类型                         | tabler 图标库                                                                                                     |
| 状态徽标   | `connection.status`              | status-badge 视觉                                                                                                 |
| 名称       | `connection.name`                | 长名截断                                                                                                          |
| 类型       | `connection.type` + 子类型       | mysql / postgresql / sqlserver / mqtt / kafka / http / websocket / redis / opcua / s7 / modbus / tdengine / opcda |
| 端点       | host:port / brokerUrl / endpoint | 脱敏（密码不在卡片上）                                                                                            |
| 数据点数量 | 后端聚合                         | 后端未提供时显 `-`                                                                                                |

**Phase 2 协议**（opcua / s7 / modbus / opcda）：

- 卡片右上角加"仅配置"小角标，hover tooltip 解释「该协议本期仅支持配置，进入工作台后只能查看配置详情」。

## 5. 卡片操作（3 个）

- 单击空白：抽屉详情
- 点"打开"按钮：进入二级工作台
- 点"⚙编辑"图标：编辑 dialog

**右键菜单已移除**——v2 不依赖右键菜单作为关键交互入口，所有操作在卡片可见。

## 6. 详情抽屉（单页滚动）

```
┌─ 头 ────────────────────────────────────────────────┐
│  [协议图标] [接入源名称]            [状态徽标]  [×]    │
├──────────────────────────────────────────────────────┤
│  基本信息                                              │
│  · 类型     · 协议子类型                              │
│  · 地址 / Broker URL / Endpoint                        │
│  · 数据库 / Topic / API 路径                          │
│  · 创建时间                                            │
│  · 更新时间                                            │
├──────────────────────────────────────────────────────┤
│  连通性测试                                            │
│                                          [测试连接]   │
│  > 结果：✅ 连接成功   响应 23ms   2026-05-15 10:32   │
├──────────────────────────────────────────────────────┤
│  关联数据点                            [全部 N → ]    │
│  · 共 N 个，跳转到数据点工作区按本源过滤              │
├──────────────────────────────────────────────────────┤
│  操作                                                  │
│  [编辑配置]  [打开工作台]  [删除]                      │
└──────────────────────────────────────────────────────┘
```

**砍掉**：

- 配置脱敏 JSON 折叠区。
- 概览 / 配置 / 解析或映射 / 预览 / 数据点 / 记录 这种多 Tab 结构。
- 「记录」（连接测试历史、预览失败、配置变更等）。
- 「能力」摘要。

**连通性测试**：

- 点击触发后端 `testConnection` 或对应协议的握手接口。
- 结果展示：成功 ✅ + 响应耗时；失败 ❌ + 错误简要 + 详情可展开。
- 结果驻留在 UI 上直到下次点击或关闭抽屉。

## 7. 新增 / 编辑接入源

**单一入口**：新增连接按钮 → ConnectionDialog。

**dialog 内分两步**：

1. **选协议类型**（grid 形态）：mysql / postgres / sqlserver / mqtt / kafka / http / websocket / redis / tdengine / opcua / s7 / modbus / opcda。Phase 2 协议显角标"仅配置"。
2. **填该协议的配置**：不同协议不同表单，公共字段 name / 备注 / 标签 + 协议特定字段。

**编辑入口**：

- 卡片"⚙"图标 → 直接打开第二步表单。
- 抽屉"编辑配置" → 直接打开第二步表单。

**砍掉**：

- "模板优先 / 协议高级"两种入口（单一入口更直接）。
- "从已有配置导入"入口（v2 不实现）。

## 8. 二级工作台（按协议类型分支）

子文档 02 只**定义占位**，二级工作台的详细页面后续可单独成文。

**占位框架**：

```
┌─ 接入源工作台头 ───────────────────────────────────┐
│  [‹ 返回]  [图标] 接入源名称   [状态]  [测试连接]  │
├─────────────────────────────────────────────────────┤
│                                                      │
│  按协议类型渲染不同主体（见下表）                     │
│                                                      │
└─────────────────────────────────────────────────────┘
```

| 协议                                          | 工作台内容（占位）                                |
| --------------------------------------------- | ------------------------------------------------- |
| 关系库（mysql/postgresql/sqlserver/tdengine） | 表浏览 + SQL 编辑 + 已保存查询管理                |
| MQTT                                          | 订阅管理 + Tag 管理 + 消息预览（短时）            |
| Kafka                                         | 短时 reader 预览（按 topic / partition / offset） |
| HTTP                                          | 一次性请求预览（method / url / headers / body）   |
| WebSocket                                     | 一次性短连接消息预览                              |
| Redis                                         | key / value 受限预览                              |
| Phase 2 工业协议（opcua/s7/modbus/opcda）     | 只读配置详情视图，无预览                          |

**v2 主文档与子文档 02 决策**：

- 删除旧 `SqlQueryWorkbench` / `MqttWorkbench` / `DataCenterNew.vue` 的 el-tabs 系统。
- 新的二级工作台以接入源为主体，每个接入源一个独立的工作台路由。

## 9. 跨模块跳转

- 卡片 / 抽屉 → 数据点工作区按 `sourceId` 过滤。
- 数据点详情"跳转来源" → 接入源详情抽屉。

**URL**：

- 接入源工作区：`/datacenter/access-source?type=mqtt&status=connected`
- 接入源详情打开：`/datacenter/access-source/:objectId`
- 接入源二级工作台：`/datacenter/access-source/:objectId/workbench`

## 10. 后端依赖与降级

| 能力                                     | 后端缺口                                                                            | 前端降级                       |
| ---------------------------------------- | ----------------------------------------------------------------------------------- | ------------------------------ |
| 接入源摘要（数据点数量、状态、地址脱敏） | 现有 connections 接口字段不全                                                       | 缺失字段显 `-`，卡片仍可渲染   |
| 连通性测试                               | 关系库 / MQTT 已有；Kafka / HTTP / WebSocket / Redis 已具备短时预览；工业协议未支持 | 不支持的协议按钮禁用 + tooltip |
| 协议子工作台对应预览                     | 各协议预览能力进度不一                                                              | 工作台内"能力未启用"占位       |
| 删除保护（关联数据点 / 引用对象检查）    | 后端需要先返回引用关系                                                              | 暂不强制，前端二次确认         |

## 11. 测试要点

- 卡片网格筛选 / 搜索 + URL 同步。
- 抽屉打开 / 关闭 + URL 同步。
- 连通性测试对不同协议调对应接口，结果展示。
- 新增 dialog：选协议 → 填表单 → 提交 → 列表刷新。
- 编辑 dialog：从卡片 / 抽屉两个入口都能进入。
- 进入二级工作台 + 返回卡片网格。
- 跨模块跳转：抽屉"关联数据点 N →" 跳转回数据点工作区按 sourceId 过滤。
