# 子文档 05：数据契约检查

> 更新时间：2026-05-15
> 上级文档：[数据中心前端 v2 设计](../2026-05-15-datacenter-frontend-v2-design.md)

## 1. 入口位置

- **NavRail 底部固定按钮**「数据契约检查」。任何模块下都可访问。
- 模块详情上下文里也可触发"针对当前对象"的契约检查（如接入源详情、计算单元详情的"检查"按钮，跳转回弹窗并预筛选作用域）。
- **不作为一级模块**。

## 2. 弹窗结构（单页滚动，不分 Tab）

## 3. 检查项分类

| 分类 | 检查内容（占位，后端定细则） |
|---|---|
| 数据点 | 定义完整性、状态、来源存在性、引用关系连续性 |
| 接入源 | 配置完整性、连通性最近状态、敏感字段是否齐全 |
| 计算单元 | 输入数据点存在、输出 `calc.*` 是否被引用、副作用治理白名单完整 |
| 报警单元 | 目标数据点存在 + 类型匹配、契约可生成 |
| artifact | 发布产物完整性、Phase 1 协议范围合规、版本一致性 |

## 4. 结果分级（4 态）

| 状态 | 含义 | 颜色 |
|---|---|---|
| ✅ `passed` | 通过 | 绿 |
| ⚠ `warning` | 警告，不阻塞发布 | 黄 |
| 🔃 `pending` | 待检查（数据依赖不齐） | 灰 |
| ❌ `failed` | 失败，建议阻塞发布 | 红 |

## 5. 跳转能力

- 每条结果右侧 LinkChip「跳转 →」按钮。
- 点击关闭弹窗 + 跳转目标模块 + 打开对象详情。
- URL 行为：弹窗关闭不留状态；模块跳转走标准 LinkChip。

## 6. 作用域

3 选 1：
- **当前项目全量**：默认。
- **指定模块**：缩到单模块（提速）。
- **指定对象**：搜索定位单个对象（如某个数据点 / 接入源），仅做与之相关的检查。

## 7. 复用最近一次结果

- 后端缓存最近一次检查结果（按 projectId 维度，TTL 由后端决定）。
- 弹窗打开时显示"复用最近一次（时间戳）"按钮，用户可选择直接看结果而不重跑。

## 8. 发布流程对接（占位，不实现）

- `dev_core` 发布前调用同一 `/contract-checks/run` 接口，作用域 = 项目全量。
- 数据中心检查结果与发布检查结果**走同一份**，不重复实现两套规则。
- v2 数据中心只承载用户主动检查入口，发布前的自动 dry-run 由 `dev_core` 调度，不在本设计范围。

## 9. 后端依赖与降级

| 能力 | 后端缺口 | 前端降级 |
|---|---|---|
| `POST /contract-checks/run` | 当前后端未实现 | 弹窗提示「能力未启用」，仅显示当前前端 mock 结果（用于演示骨架） |
| `GET /contract-checks/latest` | 当前未实现 | 复用按钮禁用 |
| 各分类检查规则 | 后端逐项实现 | 不支持的分类整段折叠区显灰 |

## 10. 测试要点

- 弹窗打开 / 关闭 + 焦点管理。
- 作用域 3 种切换。
- 开始检查 / 复用最近一次结果。
- 分类折叠 / 展开。
- 跳转 LinkChip：弹窗关闭 + 模块切换 + 对象详情打开。
- 失败 / 警告 / 待处理 / 通过 4 态渲染。
- 「能力未启用」降级展示。

## 不做的事

- 不存储检查历史（除后端最近一次缓存）。
- 不展示检查执行进度条（短时同步操作，loading 即可）。
- 不导出检查报告（v2 不实现）。
- 不在数据中心配置"哪些检查项启用"——检查规则由后端固定，前端不可配。
