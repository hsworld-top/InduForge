# 子文档 01：数据点工作区

> 更新时间：2026-05-15
> 上级文档：[数据中心前端 v2 设计](../2026-05-15-datacenter-frontend-v2-design.md)

## 1. 页面定位

- **资产目录浏览 + 治理**：用户在这里只看「定义元数据」+「引用关系」+「失效清理」。
- **链路验证**：详情抽屉里有一个「测试取值」按钮，需要的时候按一下。
- **不做**：运行态值展示、订阅推送、变更历史审计、值预览历史（这些都是运行态运维范畴）。

## 2. 主区布局


## 3. 工具栏

- 搜索框（名称 / 路径），300ms 防抖。
- 状态筛选 pill：`全部 / 活跃 / 失效 / 错误`。
- 来源类型筛选 pill：动态列出当前项目存在的类型。
- 标签筛选 popover：多选 + 关键字过滤 + "按标签分组展示"开关。
- 排序字段 pill：`更新时间 / 名称 / 路径`。
- 排序方向 pill：升 / 降。
- 工具栏右侧 icon-button：刷新、批量清理。

**移除**：质量筛选、消费方式筛选、列设置、更多筛选 popover。

## 4. 列表列字段（10 列固定）

| 列 | 宽度 | 内容 |
|---|---|---|
| 选择 | 56 | 复选框 |
| 名称 | 220 | `name` + tooltip |
| 路径 | min 280 | `path`，mono，截断 + tooltip |
| 来源 | 130 | 来源类型图标 + 文字 |
| 类型 | 100 | `dataType` mono |
| 状态 | 96 | status-badge（`活跃 / 失效 / 错误`） |
| 引用 | 96 | 引用数；为 0 时显示 `-`，> 0 时点击弹小卡片展开 |
| 标签 | 160 | 标签芯片（前 2 个 + `+N`） |
| 更新时间 | 170 | `YYYY-MM-DD HH:mm:ss` mono |
| 操作 | 200 | 行内 icon-button 群 |

**移除**：当前值、质量、写权限摘要、创建时间。

## 5. 行操作（4 个）

- 查看详情（→ 抽屉）
- 跳转来源（LinkChip）
- 复制路径
- 清理失效（仅 invalid 行）

**移除**：标签管理 / 写权限编辑独立入口（都收到抽屉里）。

## 6. 详情抽屉（单页滚动，不分 Tab）

```
┌─ 头 ────────────────────────────────────────────────┐
│  [名称]                              [状态徽标]  [×]  │
│  [path]                                       [复制]  │
├──────────────────────────────────────────────────────┤
│  基础属性                                              │
│  · 来源        · 数据类型                              │
│  · 单位        · 精度                                  │
│  · 更新时间                                            │
├──────────────────────────────────────────────────────┤
│  标签                                          [编辑]  │
│  [tag1] [tag2] [+N]                                  │
├──────────────────────────────────────────────────────┤
│  来源                                          [跳转]  │
│  · 来源对象 LinkChip                                  │
│  · 失效原因（若 invalid）                              │

│  > 结果：123.4   2026-05-15 10:32:11                  │
├──────────────────────────────────────────────────────┤
│  引用                                                  │
│  · 设计中心：xxx 页面                                  │
│  · 计算单元：xxx                                       │
│  · 报警规则：xxx                                       │
│  （引用数为 0 时整个区块不显示）                        │
├──────────────────────────────────────────────────────┤
│  运行态权限                                    [编辑]  │
│  · 写权限摘要：继承默认 / 允许 N 角色 / 禁止 N 角色     │
│  · 可读 / 可订阅                                       │
└──────────────────────────────────────────────────────┘
```

**测试取值后端口径**：
- 对 `db.query` → 触发一次查询执行。
- 对 `mqtt.tag` → 触发一次取最新缓存值（无值返回提示）。
- 对 `calc.output` → 触发一次手动运行计算单元。
- 对 `alarm.state` → 不支持，按钮禁用。
- 对 Phase 2 协议 → 后端未启用，按钮禁用 + tooltip 解释。

**砍掉**：
- 记录 Tab（变更记录、失效记录、测试历史，开发态不复盘）。
- 实时值区、最近变化列表。
- Tab 切换（单页直接滚动看完）。

## 7. 批量操作（2 个）

- 批量打标签
- 批量清理失效

**移除**：批量改写权限。

## 8. 跨模块跳转

- 行操作"跳转来源" → 接入源 / 计算单元 / 报警规则
- 抽屉"引用"区块的 LinkChip → 设计中心 / 计算单元 / 报警
- 接入源详情 → 关联数据点列表（带 sourceId 过滤跳转回数据点工作区）

**URL**：
- `/datacenter/datapoint?source=mqtt&status=active&q=温度`
- `/datacenter/datapoint/:objectId`

## 9. 后端依赖与降级

| 能力 | 后端缺口 | 前端降级 |
|---|---|---|
| 引用数 + 引用对象列表 | `GetDataPointUsages` 当前返回空 | 引用列显示 `-`，抽屉"引用"区块不展示 |
| 来源失效原因 | 后端无 `invalidReason` 字段 | 抽屉"来源"区块不展示原因 |
| 测试取值 | 按来源类型复用现有短时预览接口 | 不支持的来源类型按钮禁用 + tooltip |

## 10. 测试要点

- 筛选 / 排序 / 搜索的查询参数序列化与 URL 同步。
- 抽屉打开 / 关闭 + URL 同步。
- 「测试取值」对不同 sourceType 调对应接口。
- 批量打标签 / 清理失效。
- LinkChip 跳转后模块切换 + 详情打开。
