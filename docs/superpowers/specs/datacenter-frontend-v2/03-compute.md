# 子文档 03：计算单元工作区

> 更新时间：2026-05-15
> 上级文档：[数据中心前端 v2 设计](../2026-05-15-datacenter-frontend-v2-design.md)

## 1. 页面定位

- **写脚本、配置触发、跑调试**。开发态用户只关心这三件。
- **计算单元 = 单脚本（JS / Python）= 一个函数 = 一个 `calc.*` 数据点（最近一次 return）**。
- 用户在脚本里自由写类与方法，平台不限制结构。
- 平台代劳工程化：依赖管理（白名单勾选）、运行环境、调度、错误处理。
- **不展示**：运行态执行统计、历史调度记录、并发实例、性能指标（运行态运维范畴）。

## 2. 计算单元 ↔ 数据点抽象

### 一对一映射

- 每个计算单元**自动产生 1 个 `calc.*` 数据点**。
- 数据点路径 = **文件夹路径 + 单元名**，例如：
  - `📁 数据加工 / 功率计算` → `calc.数据加工.功率计算`
  - `📁 报表 / 子目录 / 日报` → `calc.报表.子目录.日报`
  - 根目录下的 `简单测试` → `calc.简单测试`
- 单元改名 / 移动文件夹时，数据点路径**自动同步**。

### 数据点的值

- = 脚本最近一次执行的 `return` 值。
- 类型不限：标量、字符串、对象、数组都可以。
- 不 `return` → 数据点值为 `null`。
- 脚本报错 → 数据点保留上一次值，状态切到 `error`，质量切到 `bad`。

### 触发方式对数据点更新的影响

| 触发方式   | 数据点更新时机               |
| ---------- | ---------------------------- |
| 手动       | 用户在 UI 点"运行"后更新一次 |
| 定时       | 每次 cron 命中后更新         |
| 数据点变化 | 输入数据点变化触发后更新     |

**触发只有 3 种**。不开端口、不暴露 endpoint URL。其他模块（设计中心 / 报警 / 其他计算单元）想用计算单元结果 → 绑定 `calc.*` 数据点。

### 动态传参的标准做法

如果设计中心想给计算单元"动态传参数"：

1. 配一个"数据点变化"触发，输入 `inputs.deviceId` 绑定到 `static.var.设备选择`。
2. 设计中心写入 `static.var.设备选择`。
3. 平台检测变化 → 触发执行 → return → 写到 `calc.xxx`。
4. 设计中心读 `calc.xxx` 拿结果。

整个过程走数据点抽象，不开端口。

### 副作用 + return 可以共存

- 脚本可以既写库 / 发 MQTT，又 return 状态值。
- 副作用执行；return 进数据点。

## 4. 左侧列表（树状）

**顶部**：搜索框 + "+ 新建单元" + "+ 新建文件夹"。

**树节点**：

- 文件夹：折叠 / 展开图标 + 名称 + 内部单元数。
- 单元：图标 + 名称 + 语言徽标 + 触发徽标 + 启停状态。

**操作**：

- 拖拽移动单元 / 文件夹。
- 右键 / 长按弹小菜单：重命名 / 移动 / 删除（树节点交互的小例外，简化按钮密度）。
- 文件夹空时显空状态提示。

## 5. 编辑器头条

```
┌──────────────────────────────────────────────────────────────┐
│ [📝 名称]  [JS]  [启停开关]    [保存 ⌘S] [调试 ⌘R] [删除]    │
│ 输出数据点：calc.数据加工.功率计算                  [复制]    │
└──────────────────────────────────────────────────────────────┘
```

- 单元名称：单击进入 inline 编辑（同步更新输出数据点路径）。
- 语言徽标：JS / PY，只读（创建后不可改）。
- 启停开关：active / disabled。
- 保存：脏状态高亮 + 未保存提示。
- 调试：触发调试运行（dry-run 模式）。
- 删除：二次确认 + 引用检查（若 `calc.*` 被其他模块引用，提示阻塞）。
- 输出数据点：只读展示路径 + 复制按钮，改名 / 移动时实时同步。

## 6. 编辑器折叠区

### 依赖（默认展开）

```
▼ 依赖
  ☑ lodash    ☑ dayjs     ☑ mqtt-client   ☐ mysql2
  ☐ axios     ☐ moment    ☐ uuid          ☐ ...
  [展开全部 N 个可用]                 [刷新可用库]
```

- 平台预装白名单，UI 只显示勾选状态。
- 勾选项随脚本保存。
- 脚本里 `require/import` 未勾选的库 → 保存时校验失败，错误指向具体行。

### 触发（默认展开）

```
▼ 触发方式：◉ 手动   ◯ 定时   ◯ 数据点变化

[手动]
  无额外配置。脚本仅能通过手动 / 调试运行执行。

[定时]
  Cron 表达式：[* * * * *]  [生成器]
  ▼ 高级（默认折叠）：补偿策略 / 重叠策略 / 最小触发间隔

[数据点变化]
  目标数据点：[多选 + 搜索]
  ▼ 高级（默认折叠）：死区 / 边沿触发
```

**砍掉**：错过窗口策略 / 重叠执行策略 / 死区 / 边沿触发的默认值不暴露，全部收进"高级"折叠区。

### 副作用治理（条件出现）

```
▼ 副作用治理（仅当脚本用了 ctx.sql.execute / ctx.mqtt.publish / ctx.http.* 时显示）
  · 允许写入的接入源：[多选]
  · 允许发布 Topic：[多选 + 输入]
  · 允许调用 HTTP 域名：[多选 + 输入]
  · 超时（ms）：[3000]
  · 重试次数：[0]
  · 幂等键模板：[__optional__]
```

- 脚本里没用副作用方法时整个折叠区不显示。
- 后端 SDK 检测脚本静态调用了副作用 API 才提示用户配置（首次提示弹气泡）。

## 7. Monaco 编辑器

- 语言根据单元 `language` 切换。
- **类型注入**：`inputs` / `ctx.datapoint` / `ctx.sql` / `ctx.mqtt` / `ctx.kafka` / `ctx.http` / `ctx.math` / `ctx.text` / `ctx.json` 的 d.ts。
- **依赖类型**：勾选的库自动注入其 d.ts。
- **自由组织**：用户可在脚本里 `class Foo {}`、`function bar() {}`、任意辅助函数。
- **入口约定**：脚本最后表达式 / `return` / `module.exports` 视为输出，前端展示。
- **快捷键**：`⌘S` 保存、`⌘R` 调试运行。

## 8. 底部 Tab 面板（2 个）

### Tab 1：输入

```
变量名     数据点路径
temp       mqtt.EMQX.LineA.temperature
current    mqtt.EMQX.LineA.current
[+ 添加]
```

- 每行：变量名 + 数据点路径选择器（搜索打开 popover）。
- 添加 / 删除（行末 icon）。
- 不配输入也合法（脚本里不读 `inputs`）。

### Tab 2：调试

```
输入参数（JSON）           [运行 ⌘R]   [清空]
┌──────────────────┐
│ {"a": 1, "b": 2} │
└──────────────────┘

结果   返回值 · 日志 · 副作用 · 错误
┌──────────────────────────────────────────────┐
│ [返回值]                                       │
│ { power: 4500, efficiency: 0.92 }            │
├──────────────────────────────────────────────┤
│ [日志]                                         │
│ [10:32:11] console.log: ...                  │
├──────────────────────────────────────────────┤
│ [副作用]                                       │
│ SQL: 报表库 INSERT (dry-run, 未真实执行)       │
├──────────────────────────────────────────────┤
│ [错误]                                         │
│ 无                                             │
└──────────────────────────────────────────────┘

调试模式：◉ dry-run（默认）  ◯ 真实执行
```

- 触发后端 `/compute-units/:id/debug` 接口。
- 结果分 4 区：返回值 / 日志 / 副作用 / 错误。
- dry-run 默认；切换"真实执行"需二次确认。

**砍掉**：断点调试 / 单步执行 / 变量观察 / 调用栈（v2 不实现）。调试历史记录（运行态范畴）。

## 10. 跨模块跳转

- 输入数据点路径选择器：搜索时显示当前项目所有数据点。
- 输出数据点保存后自动出现在数据点工作区。
- 数据点详情"跳转来源" → 跳到对应计算单元编辑器。
- 报警规则目标如果是 `calc.*` 数据点，可跳到源计算单元。

**URL**：

- 列表 + 当前选中：`/datacenter/compute/:objectId`
- 当前 Tab：`/datacenter/compute/:objectId/:tab?`（tab = `io | debug`）

## 11. 后端依赖与降级

| 能力                        | 后端缺口                                          | 前端降级                             |
| --------------------------- | ------------------------------------------------- | ------------------------------------ |
| 计算单元 CRUD + 启停 + 分组 | 后端有创建/运行/调试，缺 列表/更新/删除/启停/分组 | UI 禁用未启用按钮                    |
| 预装库白名单                | 后端需暴露白名单清单                              | UI 显空，提示"无可用库"              |
| 依赖勾选保存                | 后端 schema 增 `dependencies` 字段                | 字段不存在则保存时忽略，前端本地暂存 |
| dry-run                     | 后端需 dry-run 标志                               | 不支持时按钮禁用，仅真实执行         |
| 输出数据点自动同步 `calc.*` | 后端基于路径同步                                  | 不支持时保存照常，无 `calc.*` 出现   |
| 副作用治理校验              | 后端保存时校验白名单                              | 不支持时仅运行时拦截                 |
| 调试日志 / 副作用展示       | 后端需返回结构化结果                              | 不支持时仅展示返回值和错误           |

## 12. 测试要点

- 文件夹树：新建 / 重命名 / 移动 / 删除（空 / 非空文件夹）。
- 单元拖拽跨文件夹 + 输出数据点路径自动更新。
- 依赖勾选：保存 / 加载 / 类型注入。
- 触发方式切换：相应配置区显示 / 隐藏。
- 输入映射：添加 / 删除 / 数据点路径选择 popover。
- 调试：dry-run / 真实执行二次确认。
- 副作用治理：脚本静态分析触发折叠区显示。
- 引用检查：删除单元时若 `calc.*` 被引用阻塞。
- 跨模块跳转：数据点 → 计算单元 + Tab 切换。
