# 子文档 04：报警单元工作区

> 更新时间：2026-05-15
> 上级文档：[数据中心前端 v2 设计](../2026-05-15-datacenter-frontend-v2-design.md)

## 1. 页面定位

- **构建报警规则、预览契约、试算验证**。开发态只做这三件。
- **不展示**：运行态报警实例 / 事件时间线 / 确认 / 消音 / 通知中心。这些属于运行态节点侧。
- 单工程上限按 1k 规则量级设计。

## 3. 左侧列表

**顶部**：搜索框（按名称 / 目标数据点 path） + "+ 新建规则"按钮。

**列表项**：
```
┌────────────────────────────┐
│ 规则名称                    │
│ [类型徽标] [严重度徽标] [⏸]  │
│ 目标数据点路径（截断）        │
└────────────────────────────┘
```

- 类型徽标：H / L / HH / LL / Δ+ / Δ- / dV/dt / CEL。
- 严重度徽标：1 提示 / 2 低 / 3 中 / 4 高 / 5 紧急，对应文本 + 颜色。
- 启停图标按钮。

**砍掉**：分组列表（按业务分组）—— 1k 量级以下用搜索 + 严重度筛选就够。规则类型 pill 筛选。

## 4. 编辑器头条

```
┌──────────────────────────────────────────────────────────────┐
│ [📝 规则名称]  [严重度选择 ▾]  [启停开关]                      │
│                                [保存] [试算] [契约预览] [删除] │
└──────────────────────────────────────────────────────────────┘
```

- 严重度选择：下拉 5 项（1–5，文本 + 颜色徽标）。
- 试算 / 契约预览 按钮各自激活对应底部 Tab。
- 删除：二次确认。

## 6. 折叠区：抑制策略 / 消息模板

### 抑制策略（折叠，默认收起）

```
▼ 抑制策略
  合并窗口（ms）：[___]   该窗口内重复触发不新建实例
  最小触发间隔：[___]     高频抖动保护
```

### 消息模板（折叠，默认收起）

```
▼ 消息模板
  标题模板：[___]   支持 {point.path}、{point.value}、{rule.name}、{severity}
  正文模板：[textarea]
```

**砍掉**：
- 数据中心不展示通知策略、通知渠道、投递记录、回执——通知是运行态范畴。
- 「抑制 + 模板」对开发态不是必填，默认值合理（合并窗口 0 / 标题模板 `{rule.name}` / 正文模板 `数据点 {point.path} 当前值 {point.value}`）。

## 7. 底部 Tab 面板（2 个）

### Tab 1：试算

```
样本输入：◉ 使用当前数据点最近一次预览值   ◯ 手输样本

  ┌────────────────────────────┐
  │ value: 82.5                │
  │ quality: "good"            │
  │ timestamp: 1715760000000   │
  │ previousValue: 79.2  （变化率 / 偏差时用）│
  └────────────────────────────┘
                                          [运行试算]

结果：
  状态：✅ 触发 / ⭕ 不触发 / ⚠ 输入不足
  推导：value(82.5) > threshold(80) && quality == "good"   → 触发
  清除检查：value(82.5) ≮ clear(75)                          → 未清除
  消息模板渲染：
    [温度过高] 数据点 mqtt.EMQX.LineA.temp 当前值 82.5
```

- 试算**完全在数据中心计算**，不写运行态事件。
- "使用当前数据点最近一次预览值"复用计算单元里"测试取值"接口拿一次值。

### Tab 2：契约预览

```
┌──────────────────────────────────────────────────────┐
│ 节点侧执行契约                          [复制 JSON]   │
├──────────────────────────────────────────────────────┤
│ {                                                     │
│   "ruleType": "H",                                    │
│   "targetPath": "mqtt.EMQX.LineA.temp",               │
│   "condition": "value > 80 && quality == \"good\"",   │
│   "threshold": 80,                                    │
│   "clearThreshold": 75,                               │
│   "onDelayMs": 10000,                                 │
│   "offDelayMs": 30000,                                │
│   "severity": 4,                                      │
│   "message": { ... },                                 │
│   "version": "v1"                                     │
│ }                                                     │
└──────────────────────────────────────────────────────┘
```

- 契约由后端生成（`GET /alarm-rules/:id/contract`），前端只读展示。
- 只读 JSON，可复制；不允许在数据中心直接修改契约 JSON。

## 9. 跨模块跳转

- 目标数据点 → 跳到数据点工作区，按 path 打开详情。
- 数据点详情"引用"区块的"报警规则"LinkChip → 跳回报警单元编辑器。

**URL**：
- 列表 + 当前选中：`/datacenter/alarm/:objectId`
- 当前 Tab：`/datacenter/alarm/:objectId/:tab?`（tab = `test | contract`）

## 10. 后端依赖与降级

| 能力 | 后端缺口 | 前端降级 |
|---|---|---|
| 报警规则 CRUD + 启停 | 当前后端未实现（开发态完善计划阶段 5） | UI 全部禁用 + 顶部条提示「能力未启用」 |
| 目标数据点校验 | 接口待添加 | 校验跳过，保存照常 |
| 样本试算 | 接口待添加 | 试算 Tab 显「能力未启用」 |
| 契约预览 | 接口待添加 | 契约 Tab 显「能力未启用」 |
| CEL 表达式 | 后端依赖待引入 | 类型选项 CEL 禁用 + tooltip |

## 11. 测试要点

- 列表搜索 / 新建 / 删除 / 启停。
- 规则类型切换 → 表单字段动态变化。
- 目标数据点选择器：搜索 + 路径校验。
- 试算：选样本来源 / 手输样本 / 结果展示。
- 契约预览：JSON 展示与复制。
- 滞回字段：留空时使用默认回差（前端展示提示）。
- CEL 表达式校验失败时高亮 + 错误信息。
- 跨模块跳转 + URL 同步。
