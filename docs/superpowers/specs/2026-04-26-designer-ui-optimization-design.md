## 1. 背景与目标

Designer 模块需要进行 UI 风格优化，对照 DESIGN.md 设计规范，采用渐进式优化策略：
- 保留现有结构
- 逐步替换不符合规范的样式 token
- 基础层优先（CSS 变量 → 组件）

**设计系统核心原则**:
- "可信工业工作台" — 专业、克制、可信
- 低饱和中性色承载界面，主色只用于操作和状态
- 工具感明确，导航、工具栏、筛选、表格使用熟悉结构
- 宿主一致：`designer` 必须继承宿主主题语言

## 3. 实施计划

### Phase 1: CSS 变量重构
1. 在 `main.css` 中重映射 `--designer-*` 变量为目标值
2. 验证所有 UI 组件渲染正常
3. 不改变任何组件结构

### Phase 2: 字体族更新
1. 将 `main.css` 中的字体族从 Inter 改为 DESIGN.md 指定的字体栈
2. 验证中文显示正常

### Phase 3: 组件验证
1. 逐一验证工具栏、面板、按钮、输入框等组件
2. 记录并修复任何异常

---

## 4. 约束与原则

1. **不破坏功能**：只改样式，不改组件逻辑
2. **渐进式**：每次提交可独立验证
3. **保持兼容**：确保 dark mode 变量同步更新
4. **参考 DESIGN.md**：所有颜色、圆角、间距必须来自设计规范
