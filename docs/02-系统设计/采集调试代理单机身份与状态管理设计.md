# 采集调试代理单机身份与状态管理设计

## 1. 目标

采集调试代理在一台 Windows 机器上只有一个运行实例和一个稳定机器身份，并满足以下状态管理要求：

- 正常断开或退出后，中心端及时显示离线。
- 异常退出、断电或网络中断后，中心端在心跳超时后显示离线。
- 中心移除代理或本地清除注册后，中心端保留记录并显示无效。
- 无效凭据不能继续访问心跳、任务等 Agent 接口。
- 同一机器使用新注册码重新注册时复用原节点 ID，不产生重复代理记录。
- 清除本地凭据或重新安装 DevAgent 后，机器身份保持不变。

本设计不处理历史代理数据兼容。迁移时直接清理现有代理、注册码和调试任务数据，由用户重新注册代理。

## 2. 核心约束

### 2.1 单机身份

DevAgent 从 Windows 注册表读取：

```text
HKLM\SOFTWARE\Microsoft\Cryptography\MachineGuid
```

本地生成稳定机器标识：

```text
machineId = SHA256("InduForge.Collector.DevAgent|" + MachineGuid)
```

中心端只接收哈希后的 `machineId`，不接收或保存原始 `MachineGuid`。

数据库使用 `(tenant_id, machine_id)` 唯一约束。同一机器在同一租户内只能对应一条代理记录。同一机器重新注册时复用原 `collector_dev_agents.id`。

### 2.2 整机进程单例

DevAgent 使用固定名称的 `Global\Mutex`，保证不同 Windows 用户和远程桌面会话不能同时运行第二个代理进程。

- 同一桌面会话再次启动 EXE：通过命名管道通知已有进程显示窗口。
- 已有进程位于其他 Windows 会话：不启动第二个进程，提示代理已在其他会话运行。
- 本阶段不拆分 Windows 服务与托盘客户端。

## 3. 数据模型

`collector_dev_agents` 增加以下字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `machine_id` | `text NOT NULL` | DevAgent 上报的稳定机器标识 |
| `disconnected_at` | `timestamptz NULL` | 主动断开或正常退出时间 |

保留现有 `revoked_at` 字段表示注册凭据已经撤销。

增加唯一约束：

```text
UNIQUE (tenant_id, machine_id)
```

## 4. 状态模型

对外接口使用明确的 `status` 字段，不继续保留仅能表达两种状态的 `online` 字段。

| 状态 | 条件 | 含义 |
| --- | --- | --- |
| `invalid` | `revoked_at IS NOT NULL` | 注册已撤销，旧令牌无效 |
| `offline` | 主动断开，或最后心跳超过 45 秒 | 节点有效但当前不可用 |
| `online` | 未撤销、未主动断开且最后心跳不超过 45 秒 | 节点正常在线 |

状态判断优先级：

```text
revoked_at 有值                     -> invalid
disconnected_at 晚于 last_seen_at   -> offline
last_seen_at 距当前不超过 45 秒     -> online
其他                               -> offline
```

核心状态流转：

```text
首次注册                         -> online
主动断开或正常退出               -> offline
异常退出或网络中断超过 45 秒      -> offline
中心移除或本地清除注册            -> invalid
相同 machineId 使用新注册码注册   -> online，复用原 agentId
```

## 5. 注册与令牌轮换

注册请求增加 `machineId`。中心端在一个事务内完成：

1. 锁定并校验未使用、未过期的一次性注册码。
2. 按 `(tenant_id, machine_id)` 查询已有代理。
3. 不存在时创建新代理和新节点 ID。
4. 已存在时复用原节点 ID，更新名称、系统、架构、版本、IP 和协议能力。
5. 生成并覆盖新的凭据哈希。
6. 清除 `revoked_at` 和 `disconnected_at`，更新最后心跳时间。
7. 消费注册码，并将 `used_by_agent_id` 指向实际创建或复用的节点 ID。

每次重新注册都轮换 Agent Token。旧 Token 立即失效，不能继续调用任何 Agent 接口。

## 6. 断开与撤销接口

新增 Agent 自身接口：

```text
POST /api/v1/data/collector-dev/agent/disconnect
POST /api/v1/data/collector-dev/agent/revoke
```

### 6.1 主动断开

以下场景调用 `disconnect`：

- 用户点击“断开中心”。
- DevAgent 正常退出。
- Windows 正常注销或关闭应用。

中心端写入 `disconnected_at`。后续心跳成功时清除 `disconnected_at`，恢复在线。

正常退出通知使用短超时并尽力发送，中心不可达不能阻止进程退出。异常崩溃、断电和强制结束仍依赖 45 秒心跳超时。

### 6.2 清除注册

DevAgent 点击“清除注册”时调用 `revoke`：

- 撤销成功后清除本地凭据。
- 中心返回 401 或 403 时，说明凭据已经无效，直接清除本地凭据。
- 网络不可达或其他错误时保留本地凭据并提示失败，允许用户重试。

中心管理端“移除代理”使用管理员撤销能力，行为与 Agent 自身撤销一致。撤销只设置 `revoked_at`，不物理删除代理记录。

运行中的 DevAgent 收到 401 或 403 后进入未注册状态并清除本地凭据。

## 7. 心跳与重试

心跳策略：

| 场景 | 间隔 |
| --- | --- |
| 启动、注册完成、重新连接 | 立即发送 |
| 正常在线 | 15 秒 |
| 首次失败后 | 5 秒 |
| 后续连续失败 | 15 秒、30 秒 |
| 持续失败 | 保持 30 秒 |
| 恢复成功 | 回到 15 秒 |

中心端在 45 秒内未收到心跳时判定离线。任务领取轮询与心跳独立，任务接口失败不能被当作心跳失败；认证失败统一进入未注册状态。

## 8. 前端行为

### 8.1 代理管理页面

- 当前分页每 5 秒静默刷新，不显示全屏加载动画。
- 页面隐藏或组件卸载时停止轮询。
- 分别显示在线、离线、无效三种状态。
- 无效代理保留展示，并提示需要使用新注册码重新激活。
- 无效代理不再提供重复移除操作。

### 8.2 工业采集工作台

- 代理选择器排除无效代理。
- 当前选中代理每 5 秒更新状态。
- 代理被撤销后清除当前选择并禁用调试操作。
- 离线代理可以展示，但不能提交调试任务。

后端任务创建仍必须校验代理有效且在线，不能只依赖前端禁用状态。

## 9. 数据迁移

历史代理数据没有稳定 `machine_id`，不进行推断、修复或兼容。迁移按依赖顺序清理：

1. `collector_dev_tasks` 调试任务。
2. `collector_dev_registration_codes` 注册码。
3. `collector_dev_agents` 代理记录。

之后增加 `machine_id NOT NULL`、`disconnected_at` 和唯一约束。工业连接、设备、点位等工业采集业务数据不删除。

## 10. 验证标准

### 10.1 后端

- 首次注册生成节点 ID 和 Token。
- 主动断开后立即返回离线状态。
- 心跳成功后清除主动断开状态。
- 撤销后代理显示无效，旧 Token 返回 401。
- 相同 `machineId` 使用新注册码后复用原节点 ID，并恢复在线。
- 不同 `machineId` 生成不同节点 ID。
- 无效或离线代理不能创建调试任务。

### 10.2 DevAgent

- 启动后立即心跳，正常阶段每 15 秒发送。
- 失败时按 5、15、30 秒退避，恢复后回到 15 秒。
- 正常断开和退出通知中心。
- 清除注册失败时不误删本地凭据。
- 401 或 403 后清除本地凭据并进入未注册状态。
- 同一 Windows 会话再次启动时唤起原窗口。
- 其他 Windows 会话已有实例时阻止启动并显示提示。

### 10.3 前端

- 代理管理页面在 5 秒刷新窗口内反映在线、离线和无效状态。
- 无效代理不会出现在工作台代理选择器中。
- 当前代理失效或离线后不能继续提交调试任务。
