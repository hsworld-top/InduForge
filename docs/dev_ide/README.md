# IDE 管理端概览

## 模块定位

- `dev_ide` 是平台管理与运维前端，负责项目入口、平台管理、发布部署操作、节点管理和运行状态可视化。

## 核心能力

- 平台管理入口
- 工程与项目入口
- 发布与部署操作入口
- 节点、版本、运行状态与日志查看
- 平台治理相关管理视图

## 正式边界

- `dev_ide` 的主后端入口是 `dev_core`。
- `dev_ide` 不承担设计器画布编辑能力。
- `dev_ide` 不承担节点执行逻辑和平台侧数据域后端能力。

## 关键交付件

- 平台管理视图
- 项目与工程管理入口
- 发布部署操作视图
- 节点与运行状态管理视图

## 质量关注点

- 管理入口展示的发布、部署、节点状态必须与后端真实状态一致。
- 平台治理、工程管理和部署操作流程必须具备稳定冒烟验证。
- 关键运维入口不能依赖隐式状态或局部约定。
