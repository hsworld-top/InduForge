# dev_ide 概览

## 模块定位
- `dev_ide` 是平台管理与运维前端，承担项目管理、发布入口、部署运维、节点审批和运行状态查看。

## 当前已实现
- 工作台式主界面。
- 租户、用户、项目和运维入口。
- 节点卡片/列表视图、审批操作、部署状态和日志查看。
- 中英文基础国际化。

## 当前边界
- 不承接设计器画布编辑能力。
- 不负责节点执行逻辑。

## 当前重点
- 适配 Runtime 闭环后的版本、部署、健康和错误展示。
- 清理角色命名与产品化细节。
- 增加关键页面 smoke test。
