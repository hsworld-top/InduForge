# dev_ide - 项目管理与运维中心

本文档描述 dev_ide 模块的功能设计与实现。dev_ide 是 InduForge 平台的主入口，负责工程管理、用户管理、运维管理等核心功能。

## 1. 模块概述

### 1.1 定位

### 3.2 路由守卫

```typescript
// 认证检查
if (to.meta.requiresAuth && !isAuthenticated) {
  next("/login");
}

// 角色检查
if (to.meta.roles && !to.meta.roles.includes(userRole)) {
  next("/dashboard");
}

// 超级管理员限制
if (userRole === "SUPER_ADMIN" && to.name === "dashboard") {
  next("/admin");
}
```

### 4.5 工程共享机制

#### 4.5.1 可见性规则

| 可见性    | 默认 | 谁能看到工程卡片           | 谁能进入工程            |
| --------- | ---- | -------------------------- | ----------------------- |
| `private` | ✅   | 创建者 + 工程成员 + 管理员 | 同左                    |
| `shared`  | -    | 租户内所有用户             | 所有人（权限为 VIEWER） |

> **说明**：`public` 预留用于跨租户共享，暂不实现。

#### 4.5.4 共享相关 API

**获取工程列表（含共享过滤）**：

```
GET /api/v1/projects?includeShared=true
Response: { data: Project[], total: number }
```

**更新工程可见性**：

```
PUT /api/v1/projects/:id/visibility
Body: { visibility: 'private' | 'shared' }
Response: { success: true }
```

**管理工程成员**：

```
GET /api/v1/projects/:id/members
POST /api/v1/projects/:id/members
PUT /api/v1/projects/:id/members/:memberId
DELETE /api/v1/projects/:id/members/:memberId
```

### 7.2 日志类型

| 类型      | 说明                               |
| --------- | ---------------------------------- |
| `auth`    | 认证相关（登录、登出、Token 刷新） |
| `project` | 工程操作（创建、编辑、删除）       |
| `publish` | 发布操作（发布、版本管理）         |
| `deploy`  | 部署操作（部署、回滚、启停）       |
| `node`    | 节点状态（注册、在线、离线）       |
| `user`    | 用户管理（创建、编辑、权限变更）   |
| `system`  | 系统操作（配置变更、维护）         |
