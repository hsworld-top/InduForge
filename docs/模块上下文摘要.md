# 模块上下文摘要

## 1. `dev_core`
### 模块定位
- 平台统一控制面后端。

### 当前已实现能力
- 认证、多租户、用户、工程、设计页、数据连接/查询/数据点、发布、部署、节点管理。

### 核心表/接口/服务
- 表：`projects`、`design_pages`、`data_connections`、`data_queries`、`data_points`、`deployments`、`nodes`、`node_deployments`、`node_commands`。
- 服务：`publishService`、`deploymentService`、`nodeService`。
- 路由：`/api/v1/project`、`/api/v1/design`、`/api/v1/publish`、`/api/v1/deployment`、`/api/v1/node`。

### 当前缺口
- 制品协议不完整。
- 发布/部署链路测试不足。

### 目标能力
- 稳定输出 Runtime 可消费的制品。
- 提供完整部署编排和状态追踪。

### 开发优先级
- `P0`

### 依赖
- 依赖数据库、Redis、Socket.IO；被 `dev_ide`、`designer`、`datacenter`、`node_agent` 消费。

## 2. `dev_ide`
### 模块定位
- 平台管理与运维前端。

### 当前已实现能力
- 工作台、租户与用户管理、项目管理、运维管理、节点审批、部署状态展示、基础国际化。

### 核心接口
- 主要消费 `dev_core` 的项目、部署、节点、认证接口。

### 当前缺口
- 管理端文档过期。
- 自动化测试不足。
- 品牌、个人资料、状态语义等产品化细节待收口。

### 目标能力
- 成为统一的发布、部署、监控和运维入口。

### 开发优先级
- `P1`

### 依赖
- 强依赖 `dev_core`；间接依赖 `node_agent` 状态回传。

## 3. `datacenter`
### 模块定位
- 数据接入与数据语义建模前端。

### 当前已实现能力
- 关系数据库连接、查询编辑与保存、MQTT 连接与订阅、数据点管理、实时监控。

### 核心对象
- `DataConnection`、`DataQuery`、`DataPoint`、MQTT 配置与 Tag 对象。

### 当前缺口
- 计算单元、报警单元、写回设计缺失。
- 测试不足。

### 目标能力
- 从接入层演进到数据处理层。

### 开发优先级
- `P2`

### 依赖
- 依赖 `dev_core` API；被 `designer` 和 `runtime_engine` 间接消费。

## 4. `designer`
### 模块定位
- 低代码页面设计器。

### 当前已实现能力
- 页面编辑、组件树、属性编辑、事件和绑定面板、表达式引擎基础、编辑器内核、页面锁。

### 核心服务/类
- `DocumentModel`、`PageLockManager`、编辑器 store、数据服务、表达式引擎。

### 当前缺口
- 输出契约未冻结。
- 与 Runtime 的协议尚未正式对齐。
- 文档大量偏规划。

### 目标能力
- 稳定输出运行时可消费的页面和工程定义。

### 开发优先级
- `P0`

### 依赖
- 依赖 `dev_core` 项目/设计/数据接口；下游为发布制品与 Runtime。

## 5. `runtime/node_agent`
### 模块定位
- 节点控制面与执行器。

### 当前已实现能力
- 节点初始化、中心绑定、命令轮询、部署执行、日志查看、本地管理前端、静态资源嵌入。

### 核心服务
- Executor、Orchestrator、Store、Web Handler。

### 当前缺口
- 运行时业务面仍缺失。
- 前端测试不足。

### 目标能力
- 成为运行时制品的标准执行宿主。

### 开发优先级
- `P1`

### 依赖
- 依赖 `dev_core` 节点/部署 API；依赖 `runtime_engine` 作为被管进程。

## 6. `runtime/engine_*`
### 模块定位
- 页面运行时服务与前端。

### 当前已实现能力
- 当前无实现。

### 当前缺口
- 整体缺失。

### 目标能力
- 加载制品、提供页面访问、消费数据绑定、暴露健康与状态接口。

### 开发优先级
- `P0`

### 依赖
- 依赖 `publishService` 输出的制品契约、`designer` 输出 Schema、`datacenter` 数据对象定义、`node_agent` 进程托管。
