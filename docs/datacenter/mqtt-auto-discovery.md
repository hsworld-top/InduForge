# MQTT 自动发现与批量导入

## 1. 文档定位

- 本文档定义 `datacenter` 中 MQTT 自动发现与批量导入能力的正式边界。
- 本文档关注发现、映射、导入与数据点生成规则，不替代平台数据域主文档。

## 2. 能力目标

- 为 MQTT 类数据源提供变量定义快速入库能力。
- 缩短从连接接入到生成正式 `DataPoint` 的准备路径。
- 统一发现、导入、映射和落库规则。

## 3. 支持方式

| 方式          | 定位         | 说明                        |
| ------------- | ------------ | --------------------------- |
| MQTT 自动发现 | 正式能力     | 通过约定 Topic 接收变量定义 |
| CSV 批量导入  | 正式能力     | 适合离线整理后导入          |
| REST API 拉取 | 后续扩展能力 | 依赖外部系统接口稳定性      |

## 4. 对象边界

### 发现对象

- 发现对象描述变量定义来源，不直接等同于平台正式数据点。

### 数据点对象

- 发现结果在通过映射与校验后，才能转换为正式 `DataPoint`。
- `DataPoint` 才是 `designer` 和运行态可以消费的正式对象。

## 5. 正式流程

1. 配置 MQTT 连接。
2. 配置发现来源或上传 CSV。
3. 预览发现结果。
4. 做去重、命名规范和字段映射校验。
5. 选择目标变量组或数据点分组。
6. 执行导入，生成或更新 `DataPoint`。

## 6. 最小字段

| 字段             | 说明           |
| ---------------- | -------------- |
| `sourceName`     | 来源变量名     |
| `displayName`    | 展示名称       |
| `dataType`       | 数据类型       |
| `unit`           | 单位           |
| `description`    | 描述           |
| `topic`          | 来源 Topic     |
| `qualityField`   | 质量字段映射   |
| `timestampField` | 时间戳字段映射 |

## 7. 导入规则

### 新建规则

- 不存在同名数据点时直接创建。

### 冲突规则

- 已存在同名对象时，必须由用户选择覆盖、跳过或新建别名。

### 安全规则

- 自动发现只负责生成定义，不直接开放写回。

## 8. 非目标

- 不做复杂多协议统一发现中心。
- 不把发现结果直接等同为运行态订阅对象。
- 不在首版引入自动审批和自动覆盖。
