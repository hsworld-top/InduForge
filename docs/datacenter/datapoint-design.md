# 数据点（DataPoint）方案设计

## 概述

数据点是 InduForge 平台中对所有数据源的统一抽象层，提供标准化的数据访问接口，使设计器能够以一致的方式使用来自不同数据源的数据。

### 设计目标

1. **统一抽象**：将数据库查询、MQTT 变量、OPC UA 点位、WebSocket 数据、计算输出等不同类型的数据统一为「数据点」
2. **自动生成**：数据点随数据源创建自动生成，无需用户手动操作
3. **实时同步**：数据点与底层数据源保持实时同步
4. **便于使用**：设计器可通过统一接口枚举和使用所有类型的数据点

## 核心概念

### 数据点定义

```
数据点（DataPoint）= 数据源 + 数据路径 + 元数据 + 实时值
```

每个数据点具有以下特征：

| 属性         | 说明               | 示例                                       |
| ------------ | ------------------ | ------------------------------------------ |
| **路径**     | 唯一标识，层级结构 | `mqtt.EMQX.温度组.temperature`             |
| **名称**     | 显示名称           | `车间温度`                                 |
| **来源类型** | 数据来源分类       | `db.query` / `mqtt.tag` / `calc.output`    |
| **数据类型** | 值的类型           | `number` / `string` / `boolean` / `object` |
| **实时值**   | 当前值             | `25.5`                                     |
| **状态**     | 活跃/失效          | `active` / `invalid`                       |

### 数据点类型

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              数据点类型                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  📊 数据库类 (db.*)                                                         │
│  ├─ db.query    数据库查询结果                                              │
│  └─ db.table    数据库表字段（只读）                                        │
│                                                                             │
│  📡 消息类 (mqtt.* / ws.*)                                                  │
│  ├─ mqtt.tag    MQTT 变量                                                   │
│  └─ mqtt.subscription MQTT 订阅                                            │
│  └─ ws.tag      WebSocket 变量（未来支持）                                  │
│                                                                             │
│  🏭 工业协议类 (opcua.*)                                                    │
│  └─ opcua.node  OPC UA 节点（未来支持）                                     │
│                                                                             │
│  📐 计算类 (calc.*)                                                         │
│  └─ calc.output 计算单元输出                                                │
│                                                                             │
│  📌 静态类 (static.*)                                                       │
│  └─ static.var  静态变量                                                    │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 路径命名规则

```
{来源类型}.{连接/单元名称}.{分组名称}.{数据点名称}
```

**示例**：

| 路径                               | 说明                                                         |
| ---------------------------------- | ------------------------------------------------------------ |
| `db.生产库.设备统计`               | 数据库查询「设备统计」的结果数据对象                         |
| `mqtt.EMQX.温度传感器.temperature` | MQTT 连接「EMQX」下变量组「温度传感器」的 `temperature` 变量 |
| `mqtt.EMQX.设备订阅`               | MQTT 连接「EMQX」下订阅「设备订阅」的消息对象                |
| `calc.功率计算.power`              | 计算单元「功率计算」的 `power` 输出                          |
| `opcua.PLC01.设备状态.running`     | OPC UA 连接「PLC01」下「设备状态」组的 `running` 节点        |

**数据库查询路径说明**：`db.query` 类型不包含字段级分组，路径为 `db.{连接名称}.{查询名称}`，值为查询结果对象。

## 自动生成机制

### 核心原则

**用户无需手动创建数据点，数据点随数据源自动生成。**

### 生成时机

| 用户操作             | 自动生成的数据点                  |
| -------------------- | --------------------------------- |
| 保存数据库查询       | 一个查询 → 一个数据点（结果对象） |
| 创建 MQTT 变量       | 每个变量 → 一个数据点             |
| 创建 MQTT 订阅       | 一个订阅 → 一个数据点（消息对象） |
| MQTT 自动发现        | 每个发现的变量 → 一个数据点       |
| 创建 OPC UA 订阅节点 | 每个节点 → 一个数据点             |
| 保存计算单元         | 每个输出变量 → 一个数据点         |

### 数据库查询 → 数据点

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  SQL:                                                                       │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │ SELECT                                                                 │ │
│  │   COUNT(*) as device_count,                                           │ │
│  │   SUM(CASE WHEN status='online' THEN 1 ELSE 0 END) as online_count    │ │
│  │ FROM devices                                                           │ │
│  └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
│                    ↓ 保存查询「设备统计」                                   │
│                                                                             │
│  自动生成数据点:                                                            │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │ 📌 db.生产库.设备统计    (object)                                     │ │
│  │    value: { columns: [...], rows: [...], rowCount: N }               │ │
│  └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### MQTT 自动发现 → 数据点

当配置了 MQTT 自动发现功能（Tag/Data 双主题模式）时，通过元数据主题发现的变量会自动创建对应的数据点。

详细设计请参考：[MQTT 自动发现设计](./mqtt-auto-discovery.md)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  Tag Topic 消息:                                                            │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │ {                                                                      │ │
│  │   "tags": [                                                           │ │
│  │     { "name": "温度传感器_01", "dataType": "number", "unit": "℃" },  │ │
│  │     { "name": "温度传感器_02", "dataType": "number", "unit": "℃" },  │ │
│  │     { "name": "压力传感器_01", "dataType": "number", "unit": "MPa" }  │ │
│  │   ]                                                                   │ │
│  │ }                                                                      │ │
│  └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
│                    ↓ 自动发现并创建变量                                     │
│                                                                             │
│  自动生成数据点:                                                            │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │ 📌 mqtt.EMQX.自动发现组.温度传感器_01    (number)                      │ │
│  │ 📌 mqtt.EMQX.自动发现组.温度传感器_02    (number)                      │ │
│  │ 📌 mqtt.EMQX.自动发现组.压力传感器_01    (number)                      │ │
│  └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
│  Data Topic 消息:                                                           │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │ { "values": [                                                          │ │
│  │   { "N": "温度传感器_01", "V": 25.6, "T": 1704412800000, "Q": 192 },  │ │
│  │   { "N": "温度传感器_02", "V": 26.1, "T": 1704412800000, "Q": 192 }   │ │
│  │ ]}                                                                    │ │
│  └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
│                    ↓ 实时更新数据点值                                       │
│                                                                             │
│  数据点值更新:                                                              │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │ mqtt.EMQX.自动发现组.温度传感器_01.value = 25.6                        │ │
│  │ mqtt.EMQX.自动发现组.温度传感器_02.value = 26.1                        │ │
│  └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

**自动发现变量的特殊标记**：

| 属性       | 说明                             |
| ---------- | -------------------------------- |
| `source`   | 标记为 `auto_discovery`          |
| `readonly` | 变量名、数据类型等由发现消息决定 |
| `syncable` | 支持重新发现时自动更新           |

## 同步机制

### 源头变更同步

| 变更类型          | 数据点响应                 |
| ----------------- | -------------------------- |
| **查询修改**      | 更新查询数据点名称与路径   |
| **变量重命名**    | 更新数据点路径和名称       |
| **连接重命名**    | 更新所有关联数据点的路径   |
| **删除查询/变量** | 标记关联数据点为「已失效」 |

### 失效数据点处理

```
数据点状态:
  ● active  - 活跃，数据源正常
  ○ invalid - 已失效，数据源已删除或字段不存在

失效数据点:
  - 不会自动删除，避免破坏设计器中的引用
  - 在数据点列表中单独分组显示
  - 用户可手动清理失效数据点
  - 清理时会检查使用情况并提示确认
```

### 删除保护

删除数据源前，系统检查关联数据点的使用情况：

```
┌─ 删除确认 ──────────────────────────────────────────────────────────────────┐
│                                                                             │
│  ⚠️  确定删除查询「设备统计」吗？                                           │
│                                                                             │
│  此操作将影响以下内容：                                                     │
│                                                                             │
│  📌 关联数据点（1个）：                                                     │
│    • db.生产库.设备统计                                                   │
│                                                                             │
│  📐 被计算单元引用（1个）：                                                 │
│    • 设备在线率计算                                                        │
│                                                                             │
│  🎨 被设计器页面使用（2个）：                                               │
│    • 生产监控大屏                                                          │
│    • 设备总览页                                                            │
│                                                                             │
│                              [取消]    [仍然删除]                           │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 数据属性

### 基础属性（自动获取）

| 属性         | 说明     | 来源                        |
| ------------ | -------- | --------------------------- |
| `path`       | 唯一路径 | 自动生成                    |
| `sourceType` | 来源类型 | 根据数据源类型              |
| `sourceId`   | 来源 ID  | 关联的查询/变量/计算单元 ID |
| `dataType`   | 数据类型 | 从数据源推断                |
| `name`       | 名称     | 默认取查询名/变量名         |

### 扩展属性（可选配置）

| 属性                     | 说明     | 用途         |
| ------------------------ | -------- | ------------ |
| `displayName`            | 显示名称 | 界面显示     |
| `unit`                   | 单位     | 如 ℃、MPa、% |
| `precision`              | 精度     | 小数位数     |
| `min` / `max`            | 范围     | 仪表盘渲染   |
| `alarmLow` / `alarmHigh` | 报警阈值 | 预警配置     |
| `description`            | 描述     | 文档说明     |
| `tags`                   | 标签     | 分类筛选     |

## 数据刷新策略

### 数据库查询数据点

| 策略         | 说明                       | 适用场景               |
| ------------ | -------------------------- | ---------------------- |
| **手动刷新** | 用户主动触发查询执行       | 不常变化的配置数据     |
| **定时刷新** | 固定间隔自动执行查询       | 需要定期更新的统计数据 |
| **事件触发** | 特定事件触发查询并更新结果 | 关联数据变化后刷新     |

### MQTT/OPC UA 数据点

- **实时推送**：通过 Socket.IO 实时接收值变化
- **自动更新**：底层变量值变化或订阅消息到达时数据点值同步更新

### 计算输出数据点

- **依赖触发**：输入数据点变化时自动重新计算
- **定时执行**：按配置的执行间隔重新计算

### 数据点实时订阅

```javascript
// 订阅数据点
socket.emit('datapoint:subscribe', {
  projectId: 'xxx',
  paths: ['mqtt.EMQX.温度传感器.temperature', 'calc.功率计算.power'],
})

// 接收值更新
socket.on('datapoint:value', (data) => {
  // { path: 'mqtt.EMQX.温度传感器.temperature', value: 25.6, timestamp: ... }
})

// 取消订阅
socket.emit('datapoint:unsubscribe', {
  projectId: 'xxx',
  paths: ['mqtt.EMQX.温度传感器.temperature'],
})
```

## 与现有系统的关系

### 数据点 vs 数据源

| 概念       | 层级       | 说明                                 |
| ---------- | ---------- | ------------------------------------ |
| **数据点** | 数据中心层 | 统一的数据访问入口，由数据中心管理   |
| **数据源** | 设计器层   | 设计器页面级配置，引用数据点获取数据 |

```
数据中心                           设计器
┌─────────────────┐              ┌─────────────────┐
│                 │              │                 │
│  数据点         │   ─────────► │  数据源         │
│  (统一目录)     │              │  (页面配置)     │
│                 │              │                 │
│  - db.xxx       │              │  引用数据点:    │
│  - mqtt.xxx     │              │  datapoint:     │
│  - calc.xxx     │              │    mqtt.xxx     │
│                 │              │                 │
└─────────────────┘              └─────────────────┘
```

### 数据点 vs 变量

| 概念            | 作用域 | 说明                               |
| --------------- | ------ | ---------------------------------- |
| **数据点**      | 项目级 | 数据中心管理的数据，跨页面共享     |
| **变量 (vars)** | 页面级 | 设计器页面内的临时状态，如筛选条件 |

## 数据模型

### 数据库表设计

```sql
-- 数据点主表
CREATE TABLE data_points (
  id              VARCHAR(36) PRIMARY KEY,
  project_id      VARCHAR(36) NOT NULL,
  path            VARCHAR(255) NOT NULL,
  name            VARCHAR(100) NOT NULL,
  description     TEXT,

  -- 来源信息
  source_type     VARCHAR(50) NOT NULL,
  source_id       VARCHAR(36),
  source_config   JSON,

  -- 数据属性
  data_type       VARCHAR(20) NOT NULL,
  unit            VARCHAR(20),
  precision       INT,
  default_value   TEXT,

  -- 扩展属性
  min_value       DECIMAL(20,6),
  max_value       DECIMAL(20,6),
  alarm_low       DECIMAL(20,6),
  alarm_high      DECIMAL(20,6),
  tags            JSON,

  -- 刷新策略
  refresh_mode    VARCHAR(20) DEFAULT 'auto',
  refresh_interval INT,

  -- 状态
  status          VARCHAR(20) DEFAULT 'active',

  created_at      DATETIME NOT NULL,
  updated_at      DATETIME NOT NULL,

  UNIQUE KEY uk_project_path (project_id, path),
  INDEX idx_project_id (project_id),
  INDEX idx_source_type (source_type),
  INDEX idx_status (status)
);

-- 数据点使用记录表（可选，用于追踪引用关系）
CREATE TABLE data_point_usages (
  id              VARCHAR(36) PRIMARY KEY,
  datapoint_id    VARCHAR(36) NOT NULL,
  usage_type      VARCHAR(50) NOT NULL,  -- calc_input / designer_page
  usage_id        VARCHAR(36) NOT NULL,
  usage_detail    JSON,

  created_at      DATETIME NOT NULL,

  INDEX idx_datapoint_id (datapoint_id),
  INDEX idx_usage (usage_type, usage_id)
);
```
