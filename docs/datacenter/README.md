# datacenter 概览

## 模块定位
- `datacenter` 负责数据接入与数据语义建模，为设计器和运行时提供统一数据对象。

## 当前已实现
- 关系数据库连接管理。
- 查询编辑、保存与复用。
- MQTT 连接、订阅、消息查看、Tag 管理。
- 数据点主干能力与实时监控。

## 当前边界
- 当前以接入层为主，不承担页面渲染。
- 计算、报警、写回仍处于待加强阶段。

## 当前重点
- 统一数据点标识。
- 设计处理层一期对象：计算单元、报警规则、写回任务。
- 与 Designer/Runtime 对齐可消费的数据契约。
