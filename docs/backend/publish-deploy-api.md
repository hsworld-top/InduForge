# 发布部署 API

## 1. 文档定位

- 本文档定义 `dev_core` 在发布、部署、节点协同相关接口域中的正式边界。
- 本文档只描述接口职责与稳定要求，不替代 [高层设计](../高层设计.md) 和 [详细设计](../详细设计.md)。

## 2. 接口域范围

### 发布相关

- 项目发布入口
- 发布版本元数据记录
- 发布制品组织与输出

### 部署相关

- 部署计划创建
- 向节点下发启动、停止、重启、回滚类命令
- 部署状态与错误信息回传

### 节点相关

- 节点注册与审批
- 心跳与命令轮询
- 执行回执与运行状态汇总

## 3. 正式要求

### 发布接口要求

- 明确发布制品结构、版本信息与资源索引。
- 输出阻断错误与警告的区分结果。
- 使发布动作与正式契约保持一致。

### 部署接口要求

- 统一部署状态枚举。
- 明确失败、重试与回滚行为。
- 使部署计划和节点实际执行状态可追踪。

### 节点接口要求

- 明确节点运行状态、版本信息、最后错误与健康结果的回传字段。
- 支撑 `dev_ide` 与节点本地运维视图展示。
