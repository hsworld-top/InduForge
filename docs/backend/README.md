# dev_core 概览

## 模块定位

- `dev_core` 是平台治理与工程聚合后端，负责租户、用户、平台角色、工程管理、设计中心接口、平台管理接口、发布部署编排与节点协同控制。

## 核心能力

- 平台治理对象管理
- 工程与项目管理
- `designer` 设计中心相关接口
- `dev_ide` 平台管理相关接口
- 发布制品组织与部署计划编排
- 节点控制、状态汇总与运行协同

## 正式边界

- `dev_core` 是 `designer` 与 `dev_ide` 的主后端入口。
- `dev_core` 不承担长期数据域后端职责，平台侧数据域能力由 `data_service` 提供。
- `dev_core` 不承担页面运行解释、节点本地路由和运行态数据引擎职责。

## 关键对象与交付件

- 平台治理对象：租户、用户、平台角色
- 工程对象：项目、平台侧授权、工程运行态用户、工程运行态角色、设计中心元信息
- 发布部署对象：发布版本、部署计划、节点命令、节点运行回报、运行态安全快照
- 平台接口域：认证、工程、设计、发布、部署、节点、日志

## 质量关注点

- 平台治理边界与数据域边界不能混写。
- 工程管理、发布部署和节点状态必须具备可追踪性。
- 设计中心接口、平台管理接口和部署编排逻辑必须与正式文档保持一致。
