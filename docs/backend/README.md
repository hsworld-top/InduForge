# 后端概览

## 模块定位
- `dev_core` 是平台统一控制面后端，负责认证、多租户、工程、设计、数据、发布、部署、节点管理。

## 当前已实现
- `/api/v1` 主路由体系已成型。
- 已覆盖项目、设计页、数据连接/查询/数据点、发布、部署、节点、日志等核心领域。
- 已具备 NodeAgent 注册审批、心跳、命令分发和回执处理能力。

## 当前边界
- `dev_core` 负责控制面，不负责页面运行时渲染。
- Runtime 页面解释与运行宿主不在本模块内实现。
