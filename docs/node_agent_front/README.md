# NodeAgent Front 概览

## 模块定位

- `runtime/node_agent_front` 是节点本地管理前端，负责节点初始化、中心绑定、本地项目状态查看和本地运维入口。

## 核心能力

- 节点初始化与绑定入口
- 本地项目在线状态查看
- 本地日志与节点状态展示
- 本地运维与基础配置入口

## 正式边界

- `node_agent_front` 只负责节点本地管理前端，不承担节点托管后端逻辑。
- `node_agent_front` 不承担平台主控制面职责。
- 节点执行、进程托管和状态汇总由 `node_agent` 负责。

## 关键交付件

- 节点本地管理界面
- 项目在线状态视图
- 本地日志与状态视图

## 质量关注点

- 本地管理界面展示的状态必须与节点真实状态一致。
- 初始化、绑定、项目状态查看等关键入口需要稳定冒烟验证。
- 节点侧错误、失败原因与运行版本信息需要可见。
