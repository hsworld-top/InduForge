# 产品定义

## 定位与交付方式

InduForge 是私有化部署优先的工业应用开发与交付平台，主要服务集成商企业，帮助其为不同行业的工厂开发、交付和维护应用；工厂也可以购买整个平台自行开发。

| 方式         | 交付内容                                                 | 使用者                                 |
| ------------ | -------------------------------------------------------- | -------------------------------------- |
| 工程应用交付 | 固定版本应用、运行依赖、独立运行用户体系、安装和恢复能力 | 工厂管理员、操作员、工程师             |
| 整个平台交付 | 平台开发管理系统、工程开发工具、运行与节点管理能力       | 集成商或工厂自己的开发、实施和运维团队 |

两种方式共用工程和运行契约，不按客户复制平台源码。“交付工程”默认指可安装运行的应用；可编辑源码、数据模型与二次开发权是单独的交付范围，源码快照不能与运行包混淆。公开托管 SaaS 是后续可选部署方式，不是首期运行前提。

## 业务对象

| 对象                | 含义及边界                                                                                             |
| ------------------- | ------------------------------------------------------------------------------------------------------ |
| 平台实例            | 一套安装和运维边界，有自己的数据库、资产、密钥和版本；不等同于租户                                     |
| 平台组织 / 租户     | 开发人员、工程和资源的授权边界；现有代码使用 tenant                                                    |
| 客户、工厂 / 站点   | 工程服务的业务对象与现场位置；不因是一家工厂就自动创建租户                                             |
| 工程                | 可编辑的页面、场景、数据模型、计算、报警及运行权限定义                                                 |
| 正式版本（Release） | 冻结产物、契约版本、依赖与摘要，具有可验证的来源                                                       |
| 部署                | 开发版或正式版本在运行环境和节点上的实例，独立保存配置、凭据、状态与数据；客户交付使用可追溯的固定版本 |
| 运行用户            | 使用工程应用的人员，不因拥有运行账号而取得平台开发权限                                                 |

客户、工厂和交付所有权是产品建模要求；现有 tenant、project、environment、site 字段不能直接解释为完整客户管理体系。新增模型前必须确定谁授权、谁持有数据、谁负责维护。

## 两套身份体系

平台账号负责开发、发布和平台运维；工程运行账号负责应用登录、业务操作和运行域管理。平台管理员不自动成为客户应用管理员，集成商维护访问应显式授权、可撤销、可审计。

工程交付应具备首次管理员初始化、用户启停、密码重置、角色授权、会话撤销和审计。应用升级保留客户用户及业务数据；回滚应用不能静默回滚密码或已产生的生产数据。

当前控制面已有独立工程用户、密码与角色表及管理 API，但运行部署只生成统一 viewer 凭据，工程网关目前提供只读访问。现场用户名密码登录、角色发布、离线账号维护及撤销尚未贯通，不能作为已交付能力。实现证据见 [平台系统架构](./平台系统架构.md)。

## 核心使用链路

1. 安装平台并初始化组织、管理员、授权、资产存储与备份责任。
2. 配置现场数据、页面、场景、计算与报警，在受控工作区中开发调试。
3. 冻结源码与模型，构建并签名可部署版本；失败不产生可部署版本。
4. 校验现场资源，安装工程、配置现场凭据并初始化客户运行账号。
5. 持续采集、处理、展示和报警，明确断网、存储耗尽及设备异常行为。
6. 诊断、升级、回退、备份和恢复，保留可追踪的维护权限与数据归属。

## 交付要求

- 标准 Vue / React Vite 源码是页面事实来源；Designer 提供 AI、源码和预览入口，场景资源独立维护。
- 数据中心负责建模与开发调试；长期采集由现场采集器执行，生产数据处理由工程运行服务执行。
- 安装、离线制品、密钥与授权、备份恢复、升级和诊断属于正式产品能力。支持矩阵写清操作系统、CPU 架构、组件与数据版本。
- 稳定运行应不依赖厂商公网或开发控制面持续在线；部署、更新以及共享数据库、消息和授权服务的依赖单独验收。
- 断开开发控制面与关停承载现场数据库的同一台主机是不同故障；共享基础设施必须说明故障域。
- 单中心和多工作节点不代表高可用；存储复制、接管与恢复目标通过验收后才可作此承诺。
- 未完成能力说明原因和下一步，不提供假成功、占位任务或虚构健康状态。
