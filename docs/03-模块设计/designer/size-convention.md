# 设计器尺寸约定（宽度/高度）

## 1. 统一用样式 width/height + 单位，不再使用「尺寸策略」

- 属性栏只保留**尺寸**编辑（样式中的 `width` / `height`），单位可选：**auto**、**px**、**%**。
- 不再使用「尺寸策略」分组（水平策略/垂直策略 + 固定宽高），避免与「宽度/高度 + 单位」语义重复。

## 2. 单位语义

| 单位     | 含义               | 存储与渲染                                             |
| -------- | ------------------ | ------------------------------------------------------ |
| **auto** | 可延展、自适应容器 | 存为 `"auto"`；在布局/容器内时由 flex 等填满可用空间。 |
| **px**   | 固定尺寸           | 存为如 `"120px"`，按像素渲染。                         |
| **%**    | 相对于父级的百分比 | 存为如 `"50%"`，渲染时相对父容器计算。                 |

## 3. 默认尺寸

- **按钮等 UI 元素**：默认宽度/高度为 **auto**（在布局或其它 UI 容器内时自适应）。
- **直接放置在页面上**（即作为画布根或自由容器的直接子节点，而非放在布局/容器内部）时，使用**默认尺寸**（一般为固定 px，如按钮 120×40），由组件描述或创建逻辑提供，保证在自由画布上有可见占位。

## 4. 与布局的关系

- 在 **HorizontalLayout / VerticalLayout** 等流式容器内：子项常用 `width: auto` / `height: auto` 或 `100%`，由父级 `childStyle` 与布局决定。
- 在 **FreeContainer** 或根下：通常用 `absolutePos` 的 w/h 配合样式的 px 或默认尺寸，保证有明确宽高。

实现上，尺寸仅由 `node.style.width` / `node.style.height`（及绝对定位时的 `absolutePos.w/h`）驱动，属性栏通过「尺寸」编辑器（SizeEditor）统一编辑，不再依赖 horizontalPolicy/verticalPolicy/fixedWidth/fixedHeight 等 props。
