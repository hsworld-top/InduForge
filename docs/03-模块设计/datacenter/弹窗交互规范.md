# 数据中心弹窗交互规范

## 关闭规则

- 数据中心弹窗统一使用 `datacenter/src/components/shared/DcDialog.vue`。
- 弹窗默认允许点击外部遮罩关闭，详情、选择、预览类弹窗不需要额外处理。
- 编辑表单类弹窗必须传入 `dirty`。存在未保存内容时，关闭按钮、取消按钮和遮罩关闭都会先弹出确认。
- 保存、提交、加载等关键处理中状态，应传入 `closeDisabled`，避免处理中误关闭。
- 删除、批量危险操作等确认类交互继续使用明确的确认按钮或 `ElMessageBox.confirm`，不依赖遮罩关闭完成决策。

## 实现约定

- 新增弹窗优先复用 `DcDialog`，不要直接使用 `el-dialog`。
- 只有确实需要特殊行为时才覆盖 `closeOnClickModal`，并在代码中说明原因。
- 表单弹窗的 `dirty` 应基于打开时快照与当前草稿对比，保存成功后更新快照。
