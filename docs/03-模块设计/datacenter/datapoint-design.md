# 数据点开发态设计

## 1. 定位

数据点是数据中心内对查询输出、HTTP/WebSocket/Redis/Kafka 字段映射、MQTT 变量、工业采集点和计算输出的稳定开发态身份。数据中心负责配置、预览、调试和发布建模，不承诺在中心持续采集或维持节点运行态当前值。

核心规则：

- 来源工作台创建映射时原子生成数据点，映射 ID 和数据点 ID 稳定且一对一。
- 来源身份和生成点数据类型只能在所属工作台修改；通用数据点编辑接口必须拒绝这两类变更。
- 删除映射或来源前必须检查报警、计算和历史引用；无引用时将旧生成点置为 `invalid`，不静默删除运行历史。
- 新增点会自动继承来源级历史配置，但不会自动加入已有报警项。

## 2. 规范数据类型

数据库和公开 API 只允许以下 17 种类型：

```text
bool
int8  uint8  int16  uint16  int32  uint32  int64  uint64
float32  float64  decimal
string  bytes  datetime  object  array
```

`number/float/double/int/integer/long/boolean/json/byte[]/date/timestamp` 只允许在导入、协议样本等外部边界归一化，不得写入数据库或返回给公开 API。数值类型必须按位宽和有无符号校验范围。

## 3. 来源与强类型输出

| 来源 | 生成方式 | 关键规则 |
| --- | --- | --- |
| SQL 查询 | `whole` 整包、`column` 单列 | 整包为 `array`；列映射必须恰好一行，零行或多行明确失败。 |
| HTTP / WebSocket | `whole` 或 `path` | 路径使用字符串/整数片段数组，支持含点号字段和数组索引。 |
| Redis 实时 Key | 原始标量、整包或字段路径 | 批量建点先完整取样和校验，再使用一个事务写入，不允许部分成功。 |
| Kafka | 整包或字段路径 | 与 HTTP/WS/Redis 复用同一路径提取器，不使用有歧义的点分字符串。 |
| MQTT | 订阅变量解析 | 每个变量生成一个稳定点，预览会话不进入 Artifact。 |
| 工业采集 | 采集连接下的点位 | 仅声明可读采集能力；地址和数据类型使用 Manifest 与后端规则校验。 |
| 计算单元 | 规范化 `outputs` | 每个输出保存稳定键、路径、类型、单位、精度、`error|skip` 空值策略和生成点 ID。 |

来源映射的统一保存结构为：

```json
{
  "key": "temperature",
  "displayName": "温度",
  "selector": { "kind": "path", "segments": ["data", "items", 0, "value"] },
  "dataType": "float32",
  "unit": "℃",
  "precisionNum": 1,
  "sortOrder": 0
}
```

## 4. 当前值与能力

当前值响应固定返回：

```json
{
  "value": 25.6,
  "quality": "good",
  "observedAt": "2026-08-25T08:00:00Z",
  "sourceTimestamp": "2026-08-25T07:59:59Z",
  "valueOrigin": "latest_preview",
  "originLabel": "最近预览"
}
```

`valueOrigin` 至少区分实时读取、实时查询、最近预览、工业调试、计算调试、默认值和不可用。计算输入必须复用同一当前值解析器，不得用 `defaultValue` 伪造 `good` 质量和当前时间。

`get/sub/set` 能力不是无条件布尔值，每项都必须同时返回是否可用及原因。计算来源、Manifest、数据类型、启用状态和运行权限后再得出结果。工业读取点不能默认显示可写或可订阅。

## 5. 编辑、引用与批量操作

- 通用编辑只允许名称、说明、单位、精度、标签、自定义属性默认值和运行权限等点级元数据。
- 自定义属性仅支持字符串 Key/默认值，不从来源继承；内置 Key 冲突在创建时明确拒绝。
- 来源选择器使用服务端分页，统一检索普通连接、工业连接和计算单元，不在浏览器拉全量。
- 批量写入支持当前选择和全部筛选结果；“全部结果”由后端根据筛选执行，不由前端拉取所有 ID。
- 引用响应固定标记 `coverage: data_center` 并返回 provider 列表；页面只称“数据中心引用”，不声称已覆盖全平台。

## 6. 历史与报警入口

- 历史存储是来源级+点级覆盖模型，数据点页面可直接编辑单点 `inherit/off/custom`。
- 普通报警是“一个数据点的一条独立报警项”，同点可同时拥有越限、变化率、偏差、质量、陈旧和离线等不同报警。
- 数据点页面只读展示有效报警摘要并跳转报警单元，不在多个页面维护同一报警项。
- 数据点列表的批量“创建报警”只使用明确选中点，一个事务为 N 个点生成 N 条可独立维护的报警项。

## 7. 快照与 Artifact

工程快照往返数据点身份、规范类型、来源映射、计算输出、自定义属性默认值和历史/报警引用。外部密钥只往返密文及密钥版本；Artifact 只输出密钥引用。预览样本、临时会话、连通测试和当前值不进入 Artifact。
