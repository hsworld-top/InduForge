# 计算与报警开发态设计

## 1. 范围

报警发布契约唯一版本为 `alarm.item.v1`。本模块只负责开发态配置、试算、快照、发布 Artifact、配置同步接收和普通报警 Excel 维护；节点计算、活动报警、确认、消音、历史查询与通知投递不在本模块实现。

## 2. 报警项身份

普通报警的主体是数据点上的一条独立报警项，而不是可绑定多个目标的策略：

- `data_alarm_items.id` 是稳定运行身份，一条普通报警项只关联一个 `datapoint_id`。
- 同一点可以同时存在越限、变化率、偏差、离线等不同报警项。
- 多选点创建在一个事务中生成 N 条独立报警项，任一冲突时全部回滚，后续各项可分别编辑、启停和删除。
- 普通显示名称为空时按报警类型自动生成；同一点重名自动追加序号，明确填写的重名直接拒绝。
- 同一点触发指纹唯一。指纹不含显示名称、说明、严重度、通知和启用状态；完全相同的触发语义禁止重复，不同语义允许共存。
- 触发区域重叠返回稳定 `ackKey`，用户确认后可以保存并在未来分别活动。

组合报警仍是独立高级模式：不关联主体点，至少两个输入点和唯一别名，一个表达式对应一个结果条件，名称与指纹在工程内唯一，保存后默认停用。

## 3. 条件与越限等级

普通单项报警除数值越限外必须只有一个条件。条件类型固定为 `threshold/range/state/transition/text_match/rate_of_change/deviation/offline`，组合表达式是 `derived` 的输入计算方式而不是额外条件；等级固定为 `info/warning/major/critical`。

- `rate_of_change` 比较相邻采样值的绝对变化率；试算按条件的 `windowMs` 计算，或用请求中的 `sampleIntervalMs` 覆盖。
- `transition` 支持任意变化、上升沿、下降沿及明确的 `from_to`；后者必须给出不同的起始值和目标值。
- 组合表达式只能引用已配置的输入别名，支持字面量、比较、布尔运算和基础算术；不支持函数、属性访问、索引或其他可执行语法。组合试算每一步以“别名—值”对象提供输入。
- 开发态试算按模拟序列维护触发/清除延时；数值阈值、区间和偏差在已触发状态下按死区判断是否保持。节点运行态仍须按同一契约实现持久状态机。

数值越限使用 `highest_matching`，可配置任意数量的高低限等级。高限随阈值升高不得降低严重度，低限随阈值降低不得降低严重度，高低限之间必须保留正常区间。同一时刻只选择最深越限等级；高到高高及回落是同一报警身份的等级变化，回到正常区间后才恢复。

## 4. 数据模型

- `data_alarm_groups`：只负责目录层级和排序。
- `data_alarm_items`：主体点、显示名称、模式、报警类型、计算方式、表达式、指纹、通知覆盖、启停、revision 和契约。
- `data_alarm_item_conditions`：单条件或有序越限等级。
- `data_alarm_item_inputs`：组合报警输入点、别名和顺序。
- `data_alarm_project_settings`、`data_alarm_history_settings`：工程默认通知和报警历史设置。
- `data_alarm_notification_channels`、`data_alarm_notification_channel_secrets`：通知渠道及 AES-GCM 密钥。

非空目录、被引用渠道和被报警项引用的数据点禁止删除。报警历史默认开启、保留 30 天并保存通知投递记录。

## 5. API 与批量维护

报警项统一使用 `/api/v1/data/projects/{projectId}/alarm-items`。列表由后端分页并支持名称、数据点、模式、报警类型、等级、状态和目录筛选。草稿校验、试算和契约预览均只消费报警项结构。

批量接口支持明确 ID 或当前筛选结果：

- `batch-create` 为明确数据点集合创建独立报警项。
- `PATCH batch` 使用字段掩码，只修改用户勾选的启停、目录、通知或兼容条件。
- `batch-delete` 原子删除当前范围。
- “全部结果”由后端按筛选条件解析，不要求前端拉取全量 ID。

普通报警 Excel 固定包含“报警项”和“报警条件”两个 Sheet。导入经过选择文件、预览校验和确认提交；只新增或按 `alarmId + revision` 更新，不推断删除，不支持组合报警、公式或宏。

## 6. 前端交互

中央表格一行一条报警项，固定列为选择、数据点、报警类型、条件摘要、显示名称、最高等级、状态、目录和操作。窄屏时表格横向滚动，单元格保持单行。

新建普通报警可以多选兼容数据点，并明确提示会创建 N 条独立报警项。越限报警提供高低限等级；变化率、偏差、状态、转换、文本和离线各自是一条报警。批量栏支持当前选择和全部筛选结果；不兼容类型只能改公共字段。

数据点详情只读展示该点的全部报警项并跳转到中央报警单元，避免在多个入口维护同一配置。数据点列表的“创建报警”仍只使用当前明确选中点。

## 7. 快照、Artifact 与同步

`ProjectSnapshot.alarmItems` 往返报警项、条件、组合输入、目录、通知设置、渠道和报警历史。覆盖导入先清理报警引用，再恢复目录、渠道、报警项和明细；旧共享配置快照明确拒绝。

Artifact 的 `alarms.schemaVersion` 固定为 `alarm.item.v1`，普通项直接输出数据点 ID 和路径，组合项输出输入和表达式；密钥只输出引用。同步资源固定为 `alarm_item/group/project_settings/history_settings/channel`，保留 epoch、sequence、幂等和整批事务语义。
