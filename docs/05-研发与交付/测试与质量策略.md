# 测试与质量策略

## 1. 文档定位

本文档定义 InduForge 的长期测试分层、质量目标和发布前最低验证要求。

## 2. 质量目标

- AI 开发、数据配置、场景保存、构建发布、部署运行和运维主链路可回归。
- `designer`、`dev_ide`、`dev_core`、数据域、Runtime API 和 NodeAgent 边界可通过契约验证。
- Vite 开发态预览与正式 `pnpm build` 使用同一工程源码和 Runtime SDK 语义。
- Release 构建、签名、部署、探活和回滚具备稳定验证方式。
- 工程、租户、站点和运行资源隔离不能依赖隐式约定。

## 3. 测试分层

### 3.1 单元测试

验证领域校验、路径和权限规则、状态转换、Manifest、摘要以及 Runtime SDK 适配等局部逻辑。

### 3.2 组件与交互测试

- Designer 的 Pi Web、Preview/code-server 双视图、设备菜单、上下文摘要、异常状态和 HT 工具打开请求。
- Preview 与 code-server iframe 保活，以及 code-server 原生 Explorer、SCM 和 Terminal 能力。
- `dev_ide` 的标签去重、iframe 保活、鉴权注入和跨工程消息拒绝。
- 数据中心和节点本地管理的关键页面交互。

### 3.3 服务与集成测试

- `dev_core` 的工程模板、容器生命周期、上下文包、场景契约、构建与发布编排。
- `data_service` 的连接、查询、数据点、协议、计算和预览会话。
- Runtime API、数据引擎与 NodeAgent 的运行和部署状态切换。

### 3.4 契约测试

- 工程前端源码与构建产物契约。
- IFP Manifest、NodeAgent 协议和 Runtime 健康状态协议。
- HT 场景公开契约、数据点上下文和 Runtime SDK 接口。
- 开发态与运行态共享的数据域语义。

### 3.5 端到端与部署验证

- AI 修改源码后 Vite HMR 更新预览。
- HT 保存和数据点变更后生成新上下文，Pi 能读取对应版本。
- `pnpm build` 生成 `dist`，并形成可校验的 `client-assets.tar.zst`。
- HT 场景和资源进入 `runtime-artifact.tar.zst`，运行页面能按场景 ID 加载。
- NodeAgent 下载、校验、部署、探活、切换和回滚不可变 Release。
- 浏览器通过 `project-nginx` 加载静态应用，并通过 Runtime SDK 访问 API 和 WebSocket。

## 4. 模块质量责任

### 4.1 `designer`

- 验证 Pi Web、Preview、code-server、上下文摘要和 2D/3D 入口。
- 验证预览/编辑器切换不销毁 iframe，设备切换不重载 Preview。
- 验证 Vite 启停、重启、HMR、Eruda，以及 code-server Terminal 收起后保留 PTY。
- 验证初始化、编译失败、服务退出、同步失败和重试状态。
- 风险集中在 iframe/Webview 生命周期、工程身份串线、嵌套鉴权和控制命令越权。

### 4.2 `dev_ide` 与 `dev_core`

- `dev_ide` 验证标签唯一性、权限校验、URL 注入和会话恢复。
- `dev_core` 验证工程模板、开发容器、上下文原子替换、正式构建和 Release 聚合。
- 风险集中在工程隔离、部分初始化、短期票据和发布状态一致性。

### 4.3 数据域和 HT 场景

- 验证数据点与场景公开契约稳定、版本明确且上下文包无半成品。
- 验证场景私有编辑数据不泄漏为 AI 或页面的直接依赖。
- 验证运行资源与前端声明的场景 ID 一致。

### 4.4 运行系统

- `project-nginx` 验证静态文件托管、SPA 回退和 API/WebSocket 代理。
- Runtime API 验证登录、权限、数据点、场景、动作和实时推送。
- 数据引擎验证工程隔离、幂等处理、分区和故障恢复。
- NodeAgent 验证制品校验、版本切换、回滚和状态回传。

## 5. 关键验收链路

### 5.1 AI 开发到预览

```text
Pi 修改 Vite 工程源码 → 文件落盘 → Vite HMR → Designer Preview iframe 更新
```

补充验证：

- 预览 -> 文件 -> 预览后，页面交互状态、Canvas 和 HMR 连接保持。
- 文件 -> 版本 -> 文件后，编辑缓冲区、光标和未保存状态保持。
- 收起和展开 Terminal 后，PTY 与正在运行的命令保持。
- 非法 Origin、跨工程实例、过期实例和非白名单工作台命令被拒绝。

### 5.2 上下文到页面接入

```text
HT/数据中心保存 → dev_core 生成上下文包 → Pi 读取场景和数据点 → 源码使用 Runtime SDK
```

### 5.3 构建到站点运行

```text
pnpm build → client-assets → Release 签名 → NodeAgent 部署 → project-nginx → 浏览器
```

### 5.4 运行数据链路

```text
工程前端 → Runtime SDK → runtime-api → 运行数据引擎/Collector → 结果与实时推送
```

## 6. 发布前最低门禁

- 变更模块完成最接近的静态检查、编译和测试。
- 契约变更同步更新相关正式文档与契约测试。
- 页面开发链路变更同时验证 HMR 和正式 `pnpm build`。
- 场景或数据上下文变更验证版本、原子替换和缺失资源失败路径。
- 发布变更验证摘要、签名、下载、探活、切换和回滚。
- 运行系统变更验证中心断网后的已部署工程可用性。
