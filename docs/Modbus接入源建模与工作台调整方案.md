# Modbus 接入源建模与工作台调整方案

## 目标

Modbus 接入源表示一条通信通道，而不是一个唯一从站。工作台需要同时支持从站设备维度和变量分组维度：从站设备用于描述真实通信对象，变量分组只用于管理变量，不影响通信拓扑和读计划。

## 核心模型

```text
Modbus 接入源：TCP 网关或 RTU 串口总线
  ├─ 从站设备：unitId = 1
  │   ├─ 变量 A
  │   └─ 变量 B
  ├─ 从站设备：unitId = 2
  │   └─ 变量 C
  └─ 变量分组：仅用于管理变量
```

- 接入源：保存 TCP/RTU 通信通道参数、超时、重试、请求节流、默认变量参数和 TCP 冗余策略。
- 从站设备：保存 `unitId`、名称、启用状态、默认轮询周期、默认字节序/字序以及可选的超时覆盖。
- 变量：保存寄存器区、地址、数据类型、缩放、偏移、轮询周期、数据点绑定等采集定义。
- 变量分组：保存用户管理变量的目录结构，不参与采集计划合并。

## 新建/编辑接入源表单

接入源表单只负责通信通道和默认采集行为，不创建变量，不绑定唯一从站。

### 基础信息

- 接入源名称
- 描述
- Modbus 模式：TCP / RTU

### 通信参数

TCP 模式：

- IP 地址
- 端口

RTU 模式：

- 串口
- 波特率
- 数据位
- 校验位
- 停止位

### 高级参数配置

高级参数放置会影响采集通道行为或新建变量默认值的参数：

- 连接超时：建立 TCP 连接或打开串口的超时时间。
- 请求超时：单次 Modbus 请求等待响应的超时时间。
- 重试次数：请求失败后的重试次数。
- 请求间隔：两次请求之间的最小间隔，避免低端设备或串口总线被压垮。
- 最大连续读取数量：单次读取最多合并多少个寄存器或线圈。
- 最大批量请求数量：一次采集周期最多拆分多少个请求，用于限制读计划膨胀。
- 地址基准：`modicon`、`one_based`、`zero_based`，用于处理 40001/30001 和协议地址偏移。
- 默认字节序：`ABCD`、`BADC`、`CDAB`、`DCBA`。
- 默认字序：`high_first`、`low_first`。
- 默认轮询周期：新建变量、批量导入时默认带入。
- 默认从站号：新建变量、批量导入时默认带入，不表示唯一从站。

不放入高级参数：

- 全局功能码：功能码由变量寄存器区推导。
- 起始地址/读取数量：这是变量或读计划的配置。
- 唯一 slaveId：会误导为一个接入源只能访问一个从站。

### 设备冗余

仅 TCP 模式展示：

- 主网关
- 备网关
- 故障超时
- 冷却时间
- 自动回切

RTU 模式不展示可配置冗余，只说明串口冗余由采集节点侧处理。

## 工作台布局

工作台借鉴 OPC UA、MQTT、Kafka 的结构：左侧管理对象，右侧处理变量列表、预览、读计划和批量操作。

### 左侧区域

- 顶部：接入源信息、连接/断开按钮。
- 视图切换：分组 / 从站。
- 分组视图：展示变量分组树，负责筛选和管理变量分组。
- 从站视图：展示从站设备列表，负责筛选变量、维护从站默认参数和启停状态。

默认进入分组视图，因为分组是日常管理变量的主入口。

### 主区域

工具栏：

- 新建变量
- 批量导入
- 导出
- 预览
- 校验
- 读计划
- 搜索
- 筛选

变量表格：

- 多选
- 变量名
- 从站
- 寄存器区
- 地址
- 数据类型
- 字节序/字序
- 轮询周期
- 分组
- 数据点
- 操作

批量工具条：

- 已选数量
- 批量删除
- 批量移动分组
- 批量修改从站
- 批量修改轮询周期
- 批量修改字节序/字序

详情区域：

- 变量详情
- 从站详情
- 校验结果
- 读计划详情

## 从站管理

从站设备字段：

- 从站名称
- `unitId`
- 描述
- 启用/停用
- 默认轮询周期
- 默认字节序
- 默认字序
- 请求间隔覆盖值
- 请求超时覆盖值
- 重试次数覆盖值

规则：

- 同一接入源下 `unitId` 唯一。
- 变量必须归属一个从站；如果没有显式选择，使用接入源默认从站号。
- 删除从站前，如果下面存在变量，需要阻止删除并提示先迁移变量。
- 从站停用后，其变量不参与采集计划，但变量配置保留。
- 从站默认参数只影响新建变量和导入默认值，不强行覆盖既有变量。

## 变量分组

变量分组只用于管理变量。

支持能力：

- 新建分组
- 子分组
- 重命名
- 删除
- 变量移动分组
- 批量移动分组
- 导入时选择目标分组
- 表格按分组筛选

分组不影响：

- 读计划合并
- 实际请求顺序
- 从站归属
- 地址合法性

## 变量新建/编辑

变量字段：

- 变量名
- 所属从站
- 所属分组
- 寄存器区：线圈、离散输入、输入寄存器、保持寄存器
- 地址
- 数据类型
- 长度
- 字节序
- 字序
- 倍率
- 偏移
- 读写权限
- 轮询周期
- 数据点绑定
- 描述

功能码由寄存器区推导：

- 线圈：01
- 离散输入：02
- 保持寄存器：03
- 输入寄存器：04

写入功能后续按访问级别与寄存器区扩展：

- 写单线圈：05
- 写单寄存器：06
- 写多线圈：15
- 写多寄存器：16

## 导入变量

导入弹窗分两步。

第一步：导入配置。

- 上传文件 / 粘贴表格 / 批量文本
- 选择默认分组，默认当前选中分组
- 选择默认从站，默认接入源高级参数里的默认从站
- 选择默认寄存器区
- 选择默认轮询周期
- 选择默认字节序/字序

第二步：确认变量。

- 表格可编辑
- 行级校验
- 支持批量填充从站、分组、轮询周期、字节序
- 错误行明确提示
- 导入使用后端批量接口和事务

## 校验与读计划

校验规则：

- `unitId` 范围合法。
- 同接入源下从站 `unitId` 不重复。
- 变量引用的从站存在且启用状态明确。
- 变量地址范围合法。
- 数据类型长度与寄存器区匹配。
- 同一从站、同一区域下重复地址提示。
- 轮询周期过小提示风险。
- 禁用从站下的变量提示不参与采集。

读计划合并维度：

```text
connectionId + unitId + 寄存器区 + 轮询周期 + 连续地址段
```

读计划展示：

- 按从站分组。
- 展示每个从站的请求数量。
- 展示连续地址合并段。
- 展示预计周期请求数。
- 展示风险提示，例如地址不连续、周期过密、单次读取过长。

## 交付成功标准

- 新建/编辑 Modbus 接入源不再暗示一个接入源只能访问一个从站。
- 工作台能创建、编辑、删除和筛选从站设备。
- 工作台保留变量分组，并明确分组只用于管理变量。
- 变量新建、编辑、导入均可选择从站和分组。
- 变量表格支持搜索、筛选、多选和批量工具条。
- 批量删除、批量移动分组、批量修改从站/轮询/字节序使用后端批量事务接口。
- 校验和读计划能正确体现从站维度。
