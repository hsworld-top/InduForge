# runtime_node_agent AI 分发包

## 1. 模块定位
- `runtime/node_agent` 是节点侧控制面和 Runtime 宿主执行器。
- 当前阶段不再是第一批核心开发模块，主要职责转为为第二阶段独立运行态预留协议和接入点。

## 2. 当前已实现
- 节点初始化、中心绑定、命令轮询、部署执行、本地前端、日志和状态基础能力已存在。

## 3. 当前缺口
- 还没有稳定的 RuntimeEngine 可托管对象。
- 启动参数、工作目录、探活和回滚协议未冻结。
- 失败回传与日志标准仍需收敛。

## 4. 本模块目标
- 保持当前节点控制面稳定。
- 为未来 Runtime 宿主接入保留协议和目录约定。
- 不提前重投入独立运行态托管实现。

## 6. 输出物
- 版本目录预留方案
- 协议约束
- 第二阶段接入说明

## 7. 关键对象
- 部署命令
- 本地版本目录
- 当前运行版本
- 探活结果
- 回滚状态

## 8. 必须遵守的约束
- 当前阶段不提前拉高投入
- 保持协议与未来独立宿主兼容
- `/health` 和 `/status` 作为后续标准探活入口保留

## 9. 模块边界
### 本模块负责
- 运行时进程托管
- 版本目录管理
- 状态与错误上报

### 本模块不负责
- 生成制品
- 解释页面
- 渲染前端页面

## 10. 验收标准
- 协议文档和接入边界清晰
- 当前控制面不被新主线打乱
- 第二阶段可顺接独立运行态

## 11. 建议推进顺序
1. 冻结目录结构和启动参数
2. 冻结 `/health` 与 `/status` 约定
3. 保留接入位
4. 第二阶段再实现托管

## 12. 非目标
- 不做多工程并发运行
- 不做跨节点迁移
- 不重构 NodeAgent 技术栈
