# dev_ide AI 分发包

## 1. 模块定位
- `dev_ide` 是平台管理和运维前端。
- 当前阶段的核心职责是：维持项目和管理入口稳定，并为后续运行态运维展示保留扩展位。

## 2. 当前已实现
- 工作台主界面、项目入口、运维管理、节点视图、审批、日志和基础国际化已存在。

## 3. 当前缺口
- 尚未完全适配 Runtime 闭环后的版本、健康和错误展示。
- 状态语义和产品化细节还需要收口。

## 4. 本模块目标
- 保持管理前端稳定。
- 收口品牌、角色和基础产品化细节。
- 为未来运行态和运维展示保留接入口。

## 5. 直接输入
- [产品决策确认版](../产品决策确认版.md)
- [开发态预览专项计划](../开发态预览专项计划.md)
- [运行时闭环专项计划](../运行时闭环专项计划.md)
- [Runtime 健康状态协议](../contracts/runtime-health-status-contract.md)
- [dev_ide.task](../../dev_ide.task.md)

## 6. 输出物
- 稳定的项目与管理入口
- 可扩展的运维展示骨架
- 最小 smoke 测试

## 7. 关键对象
- 发布版本
- 部署记录
- 节点状态
- Runtime 状态
- 最后错误摘要

## 8. 必须遵守的约束
- 只消费平台和节点标准状态字段
- 不自行发明运行状态
- 保持角色控制与后端一致

## 9. 模块边界
### 本模块负责
- 状态展示
- 运维交互
- 失败信息呈现

### 本模块不负责
- 发布打包
- 节点执行
- 运行时页面逻辑

## 10. 验收标准
- 项目和管理入口稳定
- 文案和角色一致性清晰
- 预留未来 Runtime 展示接入口
- 核心运维页具备 smoke 测试

## 11. 建议推进顺序
1. 清理角色和文案
2. 收口品牌和个人资料等产品化细节
3. 保留运维扩展位
4. 补 smoke 测试

## 12. 非目标
- 不承接 Designer 功能
- 不重构整套后台框架
