# runtime_node_agent.task

## 模块定位
- 节点控制面与运行时宿主执行器。

## 当前已实现
- 节点初始化、绑定中心、部署执行、本地前端、日志与状态基础能力已存在。

## 本阶段目标
- 后置到第二阶段，当前以接口预留和协议约束为主，不进入第一批核心开发。

## 核心任务
1. 定义并实现 RuntimeEngine 启动/停止协议。
2. 预留版本目录、当前版本切换和回滚策略文档。
3. 预留部署失败、探活失败、回滚失败的日志与状态上报规则。
4. 保持本地前端可扩展，不提前重做页面。
5. 待共享渲染内核稳定后，再进入联调实现。

## 交付物
- 节点执行协议说明。
- 目录与状态预留方案。
- 第二阶段接入说明。

## 依赖
- 依赖 `dev_core` 的部署和节点接口。
- 依赖 `runtime_engine` 可执行产物。

## 非目标
- 不在本阶段优先实现 Runtime 进程托管。
