# dev_core.task

## 模块定位
- 平台统一控制面后端，负责工程、数据、发布、部署、节点和权限主数据。

## 当前已实现
- 项目、页面、数据连接/查询/数据点、节点、部署、发布主流程接口已存在。

## 本阶段目标
- 把 `dev_core` 从“平台控制面主数据”提升到“能稳定支撑设计器开发态预览”的后端支撑层。

## 核心任务
1. 重构 `publishService`，输出标准化 `manifest.json` 与资源清单。
2. 梳理 `project/design/data` 聚合逻辑，输出预览可消费的工程聚合结构。
3. 增加预览模式所需的数据和资源接口适配。
4. 保持发布校验与预览输入结构一致，避免两套聚合逻辑。
5. 增加工程聚合与预览主链路测试。

## 交付物
- 预览可消费的工程聚合结构。
- 与发布态一致的数据/资源接口。
- 预览主链路测试脚本。

## 依赖
- 依赖 Designer 输出契约。
- 被 `designer` 预览宿主和后续 `runtime_engine` 消费。

## 非目标
- 不在本阶段优先投入完整部署与节点联调。
