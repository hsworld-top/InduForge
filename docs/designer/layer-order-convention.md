# 设计器层级（叠放顺序）约定

## 1. 约定说明

同一父节点下的子节点，**叠放顺序由 `parent.children` 的数组顺序决定**：

- **数组下标小**（如 index 0）→ 先渲染 → 显示在**下层**（背后）
- **数组下标大**（如最后一个）→ 后渲染 → 显示在**上层**（前面）

与 CSS 中兄弟节点 DOM 顺序一致：后出现的节点盖在先出现的节点上。

## 2. 操作语义

| 操作     | 含义           | 实现（ReorderNodeCommand） |
|----------|----------------|----------------------------|
| **置顶** | 置于最前（最上层） | 移到 `children` **末尾**（index = length - 1） |
| **置底** | 置于最后（最下层） | 移到 `children` **首位**（index = 0） |
| **上移一层** | 在叠放顺序中向前一步 | 在数组中**后移**一位（index + 1） |
| **下移一层** | 在叠放顺序中向后一步 | 在数组中**前移**一位（index - 1） |

## 3. 与「放置」的关系

- **放入布局内**：新节点插入到容器的 `children` 的某个 index，叠放顺序由该 index 决定（越靠后越在上层）。
- **放到布局上层**：新节点作为容器的兄弟，插入到父的 `children` 中「在容器之后」的 index，则新节点会显示在布局容器的上面。

实现层级调整的逻辑见：`editor-core/commands/nodeCommands.js` 中的 `ReorderNodeCommand`。
