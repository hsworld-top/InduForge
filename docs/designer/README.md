# 设计器概览

## 模块定位

- `designer` 是平台设计层的核心前端，负责低代码页面、组件、变量、交互和工程内容的设计与组织。

## 核心能力

- 页面设计与组件编排
- 属性、变量、绑定与表达式配置
- 工程结构组织与设计态内容管理
- 设计态预览接入
- 发布态结构输出准备

## 正式边界

- `designer` 负责设计态与发布态内容组织，不承担平台治理与数据域后端职责。
- `designer` 通过 `dev_core` 获取设计中心与工程管理接口。
- 运行态页面解释与节点运行承载不在本模块内完成。

## 关键交付件

- 工程定义
- 页面定义
- 组件与交互定义
- 发布态结构输入

## 质量关注点

- 设计态定义与发布态结构必须稳定对齐。
- 设计态预览与运行态行为不能长期分叉。
- 组件、页面树、属性编辑与绑定机制需要稳定回归。
