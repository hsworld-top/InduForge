## 三、核心实现细节

### 3.1 图层管理系统

**命令模式实现**:

```javascript
// ReorderNodeCommand: 支持 up/down/top/bottom 四种方向
execute(doc) {
  // 1. 查找父节点
  // 2. 计算新位置
  // 3. 调整 children 数组
  // 4. 触发变更事件
}

undo(doc) {
  // 恢复原位置
}
```

**Store 方法封装**:

```javascript
const moveNodeUp = (nodeId) => {
  if (!ensureEditable()) return false;
  history.execute(new ReorderNodeCommand(nodeId, "up"));
  return true;
};
```

### 3.2 拖拽感知系统

**DragDropManager 核心算法**:

```javascript
calculateFlexInsertPosition(containerElement, event, direction) {
  // 1. 遍历容器子元素
  // 2. 根据 direction 计算 midpoint
  // 3. 比较鼠标位置与 midpoint
  // 4. 返回插入索引和插入线位置
}
```

**NodeRenderer 集成**:

- `@dragover`: 计算插入位置,显示插入线
- `@dragleave`: 清除高亮和插入线
- `@drop`: 调用 store.insertNode 插入组件

### 3.3 网格吸附

**GridSnapping 工具类**:

```javascript
snap(value) {
  return Math.round(value / this.gridSize) * this.gridSize;
}
```

**应用场景**:

- 组件拖拽移动时
- 调整组件尺寸时
- 自由容器内绝对定位时

### 3.4 样式面板架构

**分层设计**:

```
StylePanel.vue (主面板)
├── SizeEditor.vue (宽高)
├── BackgroundEditor.vue (背景)
├── BorderEditor.vue (边框)
├── PositionEditor.vue (定位)
└── SpacingEditor.vue (内外边距)
```

**数据流**:

```
用户输入 → 子组件 emit → StylePanel handleStyleChange → store.updateNode → DocumentModel 更新 → 响应式更新画布
```

## 五、技术亮点

### 5.1 命令模式应用

所有状态变更通过 Command + History 实现:

- ✅ 支持撤销/重做
- ✅ 操作原子性
- ✅ 变更事件统一管理

### 5.2 响应式数据流

使用 Pinia + storeToRefs:

- DocumentModel 更新 → 自动触发视图更新
- 无需手动 DOM 操作
- 性能优化的依赖追踪

### 5.3 模块化设计

- DragDropManager: 独立的拖拽逻辑层
- GridSnapping: 可配置的吸附工具
- 样式编辑器: 5 个独立子组件,高度复用

### 5.4 类型安全

使用 JSDoc 注释:

```javascript
/**
 * @param {DocumentModel} doc
 * @param {string} nodeId
 * @returns {boolean}
 */
```
