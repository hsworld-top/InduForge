# 发布流水线

## 1. 文档定位
- 本文档用于约束工程从平台侧发布为运行时制品的最小闭环。
- 当前事实以 `dev_core` 的 `publishService`、`deploymentService` 及平台级正式文档为准。
- 本文档不再描述过宽的未来态流水线，只定义当前阶段必须冻结的发布协议。

## 2. 当前已实现
### 2.1 已有能力
- 发布动作由平台侧触发，不在 Designer 内直接完成部署。
- 发布时已能聚合工程、页面、数据连接、查询、数据点，并生成版本包。
- 发布版本已能被部署流程消费。

### 2.2 当前缺口
- 制品结构还不够稳定，资源组织、能力声明、版本校验信息不足。
- Designer 输出模型和 Runtime 消费模型尚未完全冻结。
- 错误、警告、阻断规则没有统一标准。

## 3. 共创后建议目标
### 3.1 发布职责边界
- `designer` 负责输出发布态工程定义。
- `dev_core` 负责校验、聚合、打包、版本记录。
- `runtime/node_agent` 只消费发布制品，不参与打包。
- `runtime_engine` 只消费制品，不反向定义发布结构。

### 3.2 标准制品结构
```text
project.ifp
  manifest.json
  project/project.json
  project/pages/*.json
  project/assets/**
  project/data/points.json
  project/data/queries.json
  project/data/connections.json
```

### 3.3 `manifest.json` 最小字段
| 字段 | 说明 |
| --- | --- |
| `schemaVersion` | 制品协议版本 |
| `projectId` | 工程 ID |
| `projectCode` | 工程编码 |
| `version` | 发布版本号 |
| `entryPageId` | 入口页 ID |
| `pages` | 页面索引 |
| `assets` | 资源索引 |
| `capabilities` | 运行时能力声明 |
| `buildTime` | 打包时间 |
| `checksum` | 包摘要 |

## 4. 发布阶段定义
### 阶段 1：工程聚合
- 收集工程基础信息。
- 收集页面定义与入口页配置。
- 收集资源、连接、查询、数据点。

### 阶段 2：发布校验
- 入口页存在性校验。
- 页面引用完整性校验。
- 资源存在性校验。
- 数据引用有效性校验。

### 阶段 3：制品生成
- 生成 `project.json`。
- 生成页面文件。
- 生成数据清单文件。
- 生成 `manifest.json`。
- 打包为 `.ifp`。

### 阶段 4：版本记录
- 写入版本元数据。
- 保存制品位置与摘要。
- 标记是否可部署。

## 5. 校验结果定义
### 阻断错误
- 入口页缺失。
- 页面资源缺失。
- 必需数据对象不存在。
- 发布态 Schema 非法。

### 警告
- 非关键资源未使用。
- 可选数据点状态异常。
- 兼容字段仍存在但将在后续版本移除。

## 6. 当前阶段非目标
- 不引入复杂签名验签体系。
- 不处理差分包和增量包。
- 不在发布阶段做运行时环境绑定。
