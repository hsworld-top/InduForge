# InduForge 产品概述

InduForge 是一个面向工业应用的低代码开发平台，专为工业物联网（IIoT）和 SCADA 场景设计。平台采用微前端架构，包含三个主要应用和一个后端服务。

## 核心应用

- **dev_ide**: 主 IDE 应用，负责项目、租户和用户管理
- **datacenter**: 数据中心，管理数据库连接、SQL 查询和数据源（支持 MySQL、PostgreSQL、SQL Server）
- **designer**: 可视化页面设计器，支持拖拽组件、实时预览和数据绑定
- **dev_core**: 后端 API 服务（Node.js/Express），处理认证、数据操作和业务逻辑

## 核心特性

- 可视化拖拽式页面设计器，支持实时预览
- 多数据库支持，统一连接管理
- 基于表达式的数据绑定系统，支持实时订阅
- 丰富的组件库（工业组件、图表、UI 控件）
- 微前端架构，支持独立开发和部署
- 多租户架构，基于角色的访问控制
- 基于 DSL 的页面 Schema（JSON），声明式 UI 定义

## 目标用户

工业应用开发者、SCADA 系统集成商、运维团队，用于构建监控大屏和控制界面。
