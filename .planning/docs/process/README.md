# 过程文档索引

## 说明
- 本目录用于存放开发过程中的计划、分析、专项方案、审计稿、测试清单与历史 AI 辅助资料。
- 这里的内容用于协作和追踪，不默认代表当前正式结论。
- 正式规范、正式设计、正式契约请回到 `docs/` 查阅。

## 目录结构
- `platform/`：平台级过程资料，如专项计划、现状分析、审计稿、待确认事项。
- `designer/`：Designer 过程资料、重构草案、测试清单与历史分析。
- `datacenter/`：Datacenter 实施稿与过渡设计资料。
- `node_agent/`：NodeAgent 测试清单等过程资料。
- `runtime/`：运行时过程索引和历史说明。
- `superpowers/`：历史 superpowers 产物，按 `plans/`、`specs/` 分组。
