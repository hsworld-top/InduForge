# 正式文档体系重写执行计划

> 当前文件属于过程计划，用于记录本轮正式文档重写的阶段目标、执行顺序和当前状态，不作为正式规范源。

**Goal:** 完成 `docs/` 与 `.planning/` 的职责分层，重写平台级正式文档口径，并吸收 `data_service`、`runtime_data_service` 与节点侧运行组合进入平台文档体系。

**Architecture:** `docs/` 只承接最终态、稳定口径、正式契约与模块说明；`.planning/` 只承接当前阶段主线、推进顺序、专项计划、历史决策与 AI 过程资料。平台最终态采用“设计层 / 平台数据层 / 控制与管理层 / 共享运行内核层 / 运行与节点层”的分层结构，其中 `datacenter` 作为平台数据工作台前端，`data_service` 作为平台侧与开发态数据域服务，`runtime_data_service` 作为工程级运行态数据引擎，开发态预览与最终运行时采用共享内核、不同数据服务环境的长期结构。

**Tech Stack:** Markdown、GSD 过程文档、仓库现有 Node.js/Vue/Go 多模块单仓实现
