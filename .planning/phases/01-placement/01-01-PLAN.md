    - Test 3: Zoom division happens exactly once (input 0.5 zoom returns 2x coordinate values)
  </behavior>
  <action>
    修复 placement-utils.ts 中 eventToCanvasPosition 函数的 scroll 补偿问题：

    1. 在 eventToCanvasPosition 中添加 scroll 补偿：
       - 使用 containerElement.scrollLeft 和 containerElement.scrollTop 获取 scroll 偏移
       - 将 scroll 偏移加到 clientX/clientY 转换结果中
       - 注意：getBoundingClientRect() 不包含 scroll 偏移，这是 D-12 的核心修复

    2. 确保 zoom 除法只发生一次（不要重复除 zoom）

    3. 添加 scroll 补偿后的测试用例

    当前代码（错误）:
    ```typescript
    const rect = containerElement.getBoundingClientRect();
    const x = (event.clientX - rect.left) / zoom;
    const y = (event.clientY - rect.top) / zoom;
    ```

    修复后:
    ```typescript
    const rect = containerElement.getBoundingClientRect();
    const scrollLeft = containerElement.scrollLeft || 0;
    const scrollTop = containerElement.scrollTop || 0;
    const x = (event.clientX - rect.left + scrollLeft) / zoom;
    const y = (event.clientY - rect.top + scrollTop) / zoom;
    ```
  </action>
  <verify>
    <automated>pnpm --dir designer test --run -- placement-utils.test.ts</automated>
  </verify>
  <done>eventToCanvasPosition 正确补偿 scroll 偏移，zoom 只除一次</done>
