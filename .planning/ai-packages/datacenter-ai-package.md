# datacenter AI 分发包

## 1. 模块定位
- `datacenter` 是数据接入与数据语义建模前端。
- 当前阶段的核心职责是：稳定承接关系库与 MQTT 接入，并为处理层一期与下游引用提供统一数据对象语义。

## 2. 当前已实现
- 关系数据库连接、SQL 查询、MQTT 连接与订阅、变量组与数据点管理主链路已存在。
- 已具备基础监控与实时推送能力。

## 3. 当前缺口
- 处理层一期对象模型仍未冻结。
- 数据点统一标识与 Designer/Runtime 引用格式还需要收口。
- 异常链路与关键交互测试不足。

## 4. 本模块目标
- 保持现有接入层稳定。
- 补齐处理层一期的对象与交互边界。
- 收敛数据点引用格式，服务 `designer` 与后续 `runtime_engine`。

- 数据对象与标识约定
- 关键页面与接口适配

## 7. 关键对象
- 数据连接
- 数据查询
- MQTT 配置与订阅
- 变量组
- 数据点

## 8. 必须遵守的约束
- API 统一走 `/api/v1`
- 所有请求走统一 `request` 封装
- 不突破模块边界去实现运行态渲染
- 优先复用现有连接模型与数据对象

## 9. 模块边界
### 本模块负责
- 数据接入与处理层一期交互
- 数据点语义与引用格式
- 关键异常交互与测试

### 本模块不负责
- 平台控制面后端聚合
- Designer 编辑器逻辑
- Runtime 页面渲染

## 10. 验收标准
- 数据对象边界清晰
- 数据点引用格式稳定
- 关键页面和异常链路可验证
- 不影响现有接入主链路

## 11. 建议推进顺序
1. 收敛统一标识
2. 定义处理层对象
3. 补齐页面与接口适配
4. 增加异常与关键交互测试

## 12. 非目标
- 不扩大量新连接器类型
- 不做运行态渲染
