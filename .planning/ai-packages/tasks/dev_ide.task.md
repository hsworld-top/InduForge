# dev_ide.task

## 模块定位
- 平台管理、发布、部署、节点审批与运维前端。

## 当前已实现
- 工作台、项目入口、运维管理、节点视图、状态展示、基础国际化已存在。

## 本阶段目标
- 当前阶段以项目管理和后续运行态扩展位保留为主，不把运维闭环作为第一优先级。

## 核心任务
1. 保持项目管理和现有运维页稳定。
2. 统一品牌、头像、个人资料、系统设置入口。
3. 清理角色文案与历史 `TENANT_ADMIN` 残留。
4. 预留未来 Runtime 状态展示扩展位。
5. 增加关键页面 smoke test。

## 交付物
- 稳定的项目与管理入口。
- 可扩展的运维展示骨架。
- 管理端任务验收清单。

## 依赖
- 强依赖 `dev_core` 接口；当前阶段弱化对 `node_agent` 联调依赖。

## 非目标
- 不在本阶段承接设计器能力。
