# runtime_engine.task

## 模块定位
- 低代码工程共享渲染内核与后续运行时服务承载层。

## 当前已实现
- 当前目录为空，需要从 0 到 1 建设。

## 本阶段目标
- 先完成共享渲染内核，优先服务设计器开发态预览，并为后续独立运行态复用。

## 核心任务
1. 初始化 `runtime/engine_core`、`runtime/engine_front`、`runtime/engine_data` 基础结构。
2. 实现发布态 Schema 读取、校验、页面解析和组件注册。
3. 支持首批基础组件渲染。
4. 接入数据点、查询结果和全局变量的最小绑定能力。
5. 抽离宿主无关能力，供设计器预览宿主先复用。

## 交付物
- 共享渲染内核代码骨架。
- 页面解释与基础渲染能力。
- 供预览宿主复用的接口说明。

## 依赖
- 依赖 Designer 输出契约。
- 依赖 `dev_core` 工程聚合与数据接口。
- 当前阶段优先被 `designer` 预览宿主消费。

## 非目标
- 不在本阶段实现独立宿主、完整动作系统、多视图、桌面壳和复杂权限体系。
