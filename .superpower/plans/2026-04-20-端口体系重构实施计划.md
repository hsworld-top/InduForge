> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将仓库默认端口统一重构为 `176xx / 186xx / 196xx` 新号段，并同步根环境模板、文档和源码中的旧默认值。

**Architecture:** 以根 `.env` 作为本机实际端口的单一事实来源，以根 `.env_example` 和 `README.md` 作为默认端口展示来源。只修改端口相关事实源、直接引用旧默认值的配置和少量测试/占位文本，不扩散到无关业务代码。

**Tech Stack:** PowerShell, Node.js/Vite, Express, Go, Vue 3
