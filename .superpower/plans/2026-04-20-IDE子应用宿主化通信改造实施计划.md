# IDE 子应用宿主化通信改造 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `dev_ide`、`designer`、`datacenter` 的正式入口从 URL 敏感参数注入切换为宿主 bootstrap 握手，保留 `/debug` 独立调试入口，并支持 `handoff` 驱动的顶层标签页回附 IDE。

**Architecture:** `dev_ide` 负责生成 `handoff`、登记 iframe 上下文、响应 `APP_BOOTSTRAP_REQUEST`、接收 `AUTH_REFRESHED`/`AUTH_EXPIRED`，并继续负责主题与语言同步。`designer` 与 `datacenter` 在正式入口下改为“等待宿主 bootstrap -> 落地到本地 Storage -> 继续现有路由和请求逻辑”，在 `/debug` 路由下保留独立调试模式。`handoff` 采用 IDE 本地 `Map + localStorage` 的短期恢复票据，不新增后端接口。

**Tech Stack:** Vue 3, Vite, Pinia, Vue Router, Element Plus, Vitest（designer）, Node 内置断言/测试（dev_ide 与 datacenter）

```js
// dev_ide/src/utils/embeddedAppBridge.js
import { Storage } from './storage.js'

const HANDOFF_TTL_MS = 30 * 60 * 1000
const HANDOFF_PREFIX = 'embedded_handoff:'

export const createHandoffId = () => `hf_${crypto.randomUUID().replace(/-/g, '')}`

export const createHandoffRecord = ({
  appType,
  projectId,
  tenantId,
  tabKey,
  pageId = '',
  now = Date.now(),
}) => ({
  version: 1,
  handoff: createHandoffId(),
  appType,
  projectId,
  tenantId,
  tabKey,
  pageId,
  issuedAt: now,
  expiresAt: now + HANDOFF_TTL_MS,
})

export const buildEmbeddedAppUrl = ({ appType, handoff }) =>
  `/${appType}/?handoff=${encodeURIComponent(handoff)}`

export const createBootstrapResponse = (payload) => ({
  type: 'APP_BOOTSTRAP_RESPONSE',
  ...payload,
  debug: false,
})

export const saveHandoffRecord = (record) =>
  Storage.set(`${HANDOFF_PREFIX}${record.handoff}`, record)

export const loadHandoffRecord = (handoff) =>
  Storage.get(`${HANDOFF_PREFIX}${handoff}`, null)

export const resolveRestorePayload = (records, handoff, now = Date.now()) => {
  const record = records.find((item) => item?.handoff === handoff) ?? null
  if (!record || record.expiresAt <= now) return null
  return record
}
```

```js
// dev_ide/src/utils/storage.js
static getAllByPrefix(prefix) {
  try {
    return Object.keys(localStorage)
      .filter((key) => key.startsWith(prefix))
      .map((key) => this.get(key))
      .filter(Boolean)
  } catch (error) {
    console.warn(`Storage getAllByPrefix error for prefix "${prefix}":`, error)
    return []
  }
}
```
